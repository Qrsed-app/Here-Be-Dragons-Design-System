Usage Rules

--parchment-100 covers ≥ 80% of all surface area. --blood and --gold are reserved for elements demanding attention. Never use --emerald and --sapphire together on the same component. Never use --gold or --gold-bright as text color on parchment — use --gold-deep (5.4:1 contrast ratio, WCAG AA compliant) instead.

II

Typography

The type foundation pairs five token-driven families — Tiamat Condensed SC for display, Cinzel for accent headings, IM Fell English for serif body and flavour text, Roboto for UI labels, and JetBrains Mono for code. Apply the tag-agnostic .hbd-text-* utilities on any element to render text at the correct scale, line-height, and weight.

C·3

Callout

Callouts draw attention to important information. Use info for guidance, warning for caution, error for failures, and success for confirmations. Sage Advice is a Here Be Dragons-specific variant for in-world tips and lore — never for system status. The variant maps to an ARIA role (note / status / alert) so meaning is conveyed without colour alone.

Variants

This spell requires verbal and somatic components. Concentration must be maintained for the duration. The ritual components were consumed but the spell fizzled. Fireball erupts from your fingertip with a satisfying whomp. When in doubt, the answer is almost never "cast Fireball".

The school of magic sets the colour band and badge; the school name is always shown as visible text so identity never depends on colour alone. The card is static and presentational — focusable for reading but with no interactive behaviour.

Interactive states

The spell card is a static, presentational component — it has no hover, expand, or flip behaviour. It is focusable (a visible focus ring appears on Tab) so the content region can be reached and read by keyboard, but there are no interactive actions to demonstrate.

Form Validation

All form components use a consistent validation pattern. Errors appear inline below the field, are linked to the input via aria-describedby, carry aria-invalid="true", and announce immediately via role="alert". Success and warning states follow the same structural pattern (role="status" for non-urgent updates). This is a pattern, not a component — every form input above already implements it.

Required field convention

Mark the minority. If most of your fields are required, mark only the optional ones with (optional). If most are optional, mark the required ones with an asterisk. Required fields always carry aria-required="true"; the asterisk has aria-hidden="true" so it isn't read aloud twice.

Texture & Atmosphere

The manuscript atmosphere is applied via two fixed pseudo-elements on body. No image assets — pure CSS radial gradients and an inline SVG turbulence filter.

body::before — Stains & Vignette

Three radial gradients: warm amber at top-left (15% 10%), deeper stain at bottom-right (85% 80%), and a dark-edged vignette at center. Creates the illusion of aged, handled parchment.

body::after — Paper-Fibre Noise

Inline SVG feTurbulence fractalNoise with baseFrequency 0.85 and 4 octaves, stitchTiles enabled. Opacity 0.28, mix-blend-mode: multiply. Purely decorative — pointer-events: none, z-index: 1.

Accessibility

Both pseudo-elements use pointer-events: none so they never intercept clicks or text selection. Content sits at z-index: 2, above both texture layers. Text contrast remains WCAG 2.2 AA compliant after all overlays render.

The Draconic Tongue

Language · Primordial · Rare

Draconic is one of the oldest languages in existence and has changed very little since the first dragons taught it to their dragonborn servants. It is the language of magic — every arcane formula derives its power from Draconic phonemes.

The alphabet is composed of sharp, angular runes called dracoglyphs. Each rune encodes not merely a phoneme but a concept — consonants carry elemental power, vowels carry intent and direction.
