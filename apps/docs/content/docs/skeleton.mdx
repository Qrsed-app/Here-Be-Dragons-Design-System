import { Skeleton } from "@/registry/new-york/skeleton/skeleton";

The HBD skeleton is a token-backed placeholder shape that shimmers while content
loads. The element itself is `aria-hidden` — the surrounding container that
becomes the real content should own the `aria-busy` loading affordance.

## Variants

Five built-in shapes: `text`, `text-sm`, `text-lg`, `circle`, and `rect`. The
`rect` variant requires an explicit `height`.

## Sizing

Use the `width` and `height` props to control dimensions. These are
value-driven (carried via inline style) since they vary per layout, while every
other style comes from tokens.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Skeleton variant="text" width="100%" />
      <Skeleton variant="text" width="75%" />
      <Skeleton variant="text" width="50%" />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Skeleton variant="text" width="100%" />
    <Skeleton variant="text" width="75%" />
    <Skeleton variant="text" width="50%" />
    ```
  </Tab>
</Tabs>

## No shimmer

Set `noShimmer` for a static placeholder — useful for a reduced-motion look or
when many skeletons would otherwise animate at once.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Skeleton variant="rect" width="120px" height="80px" noShimmer />
      <Skeleton variant="circle" noShimmer />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Skeleton variant="rect" width="120px" height="80px" noShimmer />
    <Skeleton variant="circle" noShimmer />
    ```
  </Tab>
</Tabs>

## Usage

Compose multiple skeletons to mirror the shape of the content being loaded. Put
`aria-busy` and a label on the wrapping container, not on the skeletons.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <div
        aria-busy="true"
        aria-label="Loading spell card"
        style={{ display: "flex", gap: "1rem", alignItems: "center", width: "320px" }}
      >
        <Skeleton variant="circle" />
        <div style={{ display: "flex", flexDirection: "column", gap: "0.5rem", flex: 1 }}>
          <Skeleton variant="text-lg" width="70%" />
          <Skeleton variant="text" width="100%" />
          <Skeleton variant="text-sm" width="40%" />
        </div>
      </div>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <div
      aria-busy="true"
      aria-label="Loading spell card"
      style={{ display: "flex", gap: "1rem", alignItems: "center" }}
    >
      <Skeleton variant="circle" />
      <div style={{ display: "flex", flexDirection: "column", gap: "0.5rem", flex: 1 }}>
        <Skeleton variant="text-lg" width="70%" />
        <Skeleton variant="text" width="100%" />
        <Skeleton variant="text-sm" width="40%" />
      </div>
    </div>
    ```
  </Tab>
</Tabs>
