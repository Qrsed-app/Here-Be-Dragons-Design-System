The HBD navbar reproduces the legacy `hbd-navbar` web component 1:1: a desktop
row (logo / centred nav / actions) plus a full-viewport mobile menu that mirrors
the same logo, links and actions. Below the `--hbd-navbar-mobile-breakpoint`
(768px) the desktop nav hides and a hamburger reveals the mobile menu, which is
portalled to the body with scroll-lock, a focus trap, return-focus and
Escape-to-close.

It is a compound component: compose it from `Navbar.Logo`, `Navbar.Link` and
`Navbar.Actions`. Links auto-mark `.is-active` + `aria-current="page"` when their
`href` matches the current pathname, or you can force it with the `active` prop.

## Variants

Toggle `bordered`, `transparent` or `sticky` to change the bar's chrome. Use
`sticky` to pin the navbar to the top of the viewport as the page scrolls.

## Mobile menu

Narrow the viewport below 768px (or resize the preview pane) to collapse the
desktop nav and reveal the hamburger. Tapping it opens the off-canvas menu, which
mirrors the logo, links and actions. The menu locks body scroll, traps focus,
closes on `Escape`, restores focus to the trigger on close, and auto-closes if
the viewport grows back above the breakpoint. Use `defaultOpen`/`open` +
`onOpenChange` to control it, and `onOpen`/`onClose` to react to its lifecycle.
