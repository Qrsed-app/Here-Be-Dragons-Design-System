---
title: OTP Input
description: A row of single-character cells for one-time passwords and verification codes, with auto-advance, paste, and keyboard navigation.
---

import { OtpInput } from "@/registry/new-york/otp-input/otp-input";
import { OtpInputControlledDemo } from "@/components/demos/otp-input-demo";

The HBD OTP input renders a row of single-character cells that auto-advance on
entry, accept clipboard paste (splitting across cells), and support arrow +
backspace navigation. It reuses the shared `.hbd-field` label / hint / error
chrome from the input component.

## Lengths

Only 4- or 6-cell layouts are supported; any other `length` falls back to 6.

## Type and separator

Use `type="alphanumeric"` to allow letters as well as digits, and `separator`
to split the two groups of three on a 6-cell field.

## States

`hint` shows helper text, `error` switches the field into the invalid state
(and is announced via `role="alert"`), `success` tints the filled cells, and
`disabled` greys out every cell.

## Controlled

Drive the value with `value` + `onValueChange`, and react to a fully filled
field with `onComplete`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <OtpInputControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import * as React from 'react';
    import { OtpInput } from '@/registry/new-york/otp-input/otp-input';

    function VerificationField() {
      const [code, setCode] = React.useState('');

      return (
        <OtpInput
          label="Verification code"
          length={6}
          value={code}
          onValueChange={setCode}
          onComplete={(value) => console.log('complete', value)}
          hint="Enter the 6-digit code we sent to your raven."
        />
      );
    }
    ```

  </Tab>
</Tabs>
