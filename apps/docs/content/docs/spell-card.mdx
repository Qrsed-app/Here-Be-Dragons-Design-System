The HBD spell card is a presentational, token-backed port of the legacy
`<hbd-spell-card>`. It renders a spell's name, level, school of magic, meta
fields (casting time, range, components, duration), optional ritual /
concentration tags, a description, "At Higher Levels" content, and a footer.

The description is passed as `children` (inline text); the component wraps it in
its own `<p>`, so pass a plain string rather than block markdown.

## Schools

The `school` prop sets the colour band and eyebrow. Unknown values are ignored.

    ```tsx
    <SpellCard
      name="Fireball"
      level="3"
      school="evocation"
      castingTime="1 action"
      range="150 feet"
      components="V, S, M"
      duration="Instantaneous"

      A bright streak flashes to a point you choose, then blossoms into an explosion of flame.
    ```

## Levels

`level` accepts a number or string. The values `"cantrip"` and `"0"` render the
**Cantrip** badge; anything else renders `Lvl {level}`.

## Tags and states

`ritual` and `concentration` render tags with matching modifiers, and `selected`
applies the gold border + offset shadow.

  </Tab>
</Tabs>

## Higher levels and footer

Use `higherLevels` for the "At Higher Levels" block and `footer` for source or
tag metadata.

<Tabs items={['Preview', 'Code']}>

  </Tab>
  <Tab value="Code">
    ```tsx
    <SpellCard
      name="Magic Missile"
      level="1"
      school="evocation"
      castingTime="1 action"
      range="120 feet"
      components="V, S"
      duration="Instantaneous"
      higherLevels="The spell creates one more dart for each slot level above 1st."
      footer="Player's Handbook · p. 257"
    >
      You create three glowing darts of magical force, each dealing 1d4 + 1 force damage.
    </SpellCard>
    ```
