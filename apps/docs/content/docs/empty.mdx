---
title: Empty State
description: Token-backed placeholder for empty, error, and success screens with themed illustrations.
---

import { EmptyState } from "@/registry/new-york/empty/empty";
import { Button } from "@/registry/new-york/button/button";

The HBD empty state fills empty, error, or success screens with a decorative
illustration, heading, description, and an optional actions row. Pick a
canonical `template` for sensible defaults, or override `heading`/`description`
and pass action `children`.

## Templates

Each `template` ships its own illustration plus default copy. Error templates
pick up an error tint; success templates a success tint.

## With actions

Pass action elements as `children`; they render into the actions row.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <EmptyState template="no-data">
        <Button variant="primary">Add item</Button>
        <Button variant="default">Import</Button>
      </EmptyState>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { EmptyState } from '@/components/ui/empty';
    import { Button } from '@/components/ui/button';

    <EmptyState template="no-data">
      <Button variant="primary">Add item</Button>
      <Button variant="default">Import</Button>
    </EmptyState>
    ```

  </Tab>
</Tabs>

## Inline layout

Set `inline` to place the illustration to the left of the text — useful inside
cards or list rows.

## Custom copy

Override the template defaults with `heading` and `description`, and choose the
semantic heading level with `headingLevel`.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <EmptyState
        template="no-results"
        heading="No quests match your search"
        description="Try a different keyword or clear your filters to see everything."
        headingLevel="3"
      >
        <Button variant="default">Clear filters</Button>
      </EmptyState>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <EmptyState
      template="no-results"
      heading="No quests match your search"
      description="Try a different keyword or clear your filters to see everything."
      headingLevel="3"
    >
      <Button variant="default">Clear filters</Button>
    </EmptyState>
    ```
  </Tab>
</Tabs>
