The HBD accordion condenses long, secondary content into expandable sections,
reproducing the legacy `.hbd-accordion` look 1:1 with token-backed component CSS.
It uses a compound `Accordion` + `Accordion.Item` API, works uncontrolled
(`defaultValue` / `defaultValues`) or controlled (`value` / `values`), and is
fully keyboard accessible — each trigger is a real `<button>` with
`aria-expanded`, and Arrow / Home / End keys move focus between triggers.

## Usage

In single mode (the default), opening an item collapses the previously open one.
Each item is identified by its `value`, falling back to its index.

    ```tsx
        Medieval cartographers inked the phrase on the uncharted edges of
        their maps to mark dangerous or unexplored territory.
      </AccordionItem>
      <AccordionItem value="usage" title="When should I reach for an accordion?">

      </AccordionItem>

    </Accordion>
    ```

## Modes

Set `mode="multi"` to let items toggle independently — any number can be open at
once. Use `defaultValues` (multi) instead of `defaultValue` (single) to seed the
open set.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <AccordionMultiDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Accordion mode="multi" defaultValues={["compass", "sextant"]}>
      <AccordionItem value="compass" title="Compass">
        Points the way north so a navigator can hold a steady bearing.
      </AccordionItem>
      <AccordionItem value="sextant" title="Sextant">
        Measures the angle between a star and the horizon to fix latitude.
      </AccordionItem>
      <AccordionItem value="astrolabe" title="Astrolabe">
        An older instrument for locating the positions of stars.
      </AccordionItem>
    </Accordion>
    ```

## Variants

Three boolean variants control the chrome: `bordered` boxes the whole group,
`divided` adds hairline rules between items, and `flush` strips the border for
embedding inside an existing surface.

## States

A disabled `Accordion.Item` renders a dimmed, non-interactive trigger that is
also skipped by roving keyboard navigation.

## Controlled

Drive the open state from React with `value` + `onValueChange` (single mode) or
`values` + `onValueChange` (multi mode). The callback receives the new key
(`string | null`) for single mode or the key array for multi mode.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <AccordionControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [open, setOpen] = React.useState<string | null>('north');

    <Accordion value={open} onValueChange={(v) => setOpen(v as string | null)}>
      <AccordionItem value="north" title="Northern passage">…</AccordionItem>
      <AccordionItem value="south" title="Southern passage">…</AccordionItem>
      <AccordionItem value="east" title="Eastern passage">…</AccordionItem>
    </Accordion>
    ```

  </Tab>
</Tabs>
