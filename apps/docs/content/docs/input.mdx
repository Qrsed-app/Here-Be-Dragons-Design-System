title: Input

import { Input } from "@/registry/new-york/input/input";

The HBD `Input` is the canonical form field. It owns the shared `.hbd-field`
chrome — label, hint, error/success messages, character count, prefix/suffix,
and the password eye toggle — using token-backed component CSS, not Tailwind
utilities. Restricted `type` values follow the HBD allow-list (`text`, `email`,
`password`, `search`, `tel`, `url`, `number`); anything else falls back to `text`.

## States

The `error` and `success` props drive the validation chrome. A non-empty `error`
sets `aria-invalid` and shows the error message; `success` shows only when there
is no error. The `hint` is hidden while an error or success message is visible.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Input label="With hint" hint="Use 3–20 characters." placeholder="username" />

        error="That email is already taken."

## Prefix & suffix

Static text rendered inside the field's leading or trailing edge. The suffix is
ignored for `type="password"`, where the eye toggle owns that slot.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Input label="Price" type="number" prefix="$" placeholder="0.00" />
      <Input label="Weight" type="number" suffix="kg" placeholder="0" />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Input label="Price" type="number" prefix="$" placeholder="0.00" />
    <Input label="Weight" type="number" suffix="kg" placeholder="0" />
    ```
  </Tab>
</Tabs>

## Password & character count

`type="password"` adds an accessible show/hide eye toggle. Setting `maxLength`
enables the live character counter, which announces politely as you type.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Input label="Password" type="password" placeholder="••••••••" required />
      <Input label="Bio" hint="Keep it short." maxLength={80} defaultValue="Here be dragons." />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Input label="Password" type="password" placeholder="••••••••" required />
    <Input label="Bio" hint="Keep it short." maxLength={80} defaultValue="Here be dragons." />
    ```
  </Tab>
</Tabs>
