import { Badge } from "@/registry/new-york/badge/badge";

The HBD badge reproduces the legacy `.hbd-badge` look 1:1 using token-backed
component CSS. It has two modes: a **count** badge that displays a number
(capped via `max`) and a **dot** badge that shows a small colour-only
indicator. Accessible names are derived from `label` and the real count.

## Variants

The `variant` prop maps to the semantic colour roles `primary`, `success`,
`warning`, `error`, and `neutral` (the default).

## Count

A numeric `count` is rendered as text. Values above `max` (default `99`) are
capped to `"{max}+"`, while the accessible name still reports the real count.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Badge variant="primary" count={3} />
      <Badge variant="primary" count={42} />
      <Badge variant="error" count={128} />
      <Badge variant="error" count={1500} max={999} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Badge variant="primary" count={3} />
    <Badge variant="primary" count={42} />
    {/* 128 > 99 → renders "99+" */}
    <Badge variant="error" count={128} />
    {/* custom cap → renders "999+" */}
    <Badge variant="error" count={1500} max={999} />
    ```
  </Tab>
</Tabs>

## Dot

The `dot` variant renders a small colour-only indicator with no text. Pass a
`label` so it exposes an accessible `role="status"` name; without one it stays
purely decorative.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Badge variant="success" dot label="Online" />
      <Badge variant="warning" dot label="Away" />
      <Badge variant="error" dot label="Offline" />
      <Badge variant="neutral" dot label="Unknown" />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Badge variant="success" dot label="Online" />
    <Badge variant="warning" dot label="Away" />
    <Badge variant="error" dot label="Offline" />
    <Badge variant="neutral" dot label="Unknown" />
    ```
  </Tab>
</Tabs>

## Usage

Pair `label` with `count` to give count badges a meaningful accessible name —
for example a notification count reads as `"Notifications, 12"`.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Badge variant="primary" label="Notifications" count={12} />
      <Badge variant="error" label="Errors" count={3} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Badge variant="primary" label="Notifications" count={12} />
    <Badge variant="error" label="Errors" count={3} />
    ```
  </Tab>
</Tabs>
