The HBD callout surfaces inline status messages. It ports the legacy
`.hbd-callout` look 1:1 using token-backed component CSS, and wires the correct
ARIA `role` per variant (`note`, `status`, or `alert`) automatically.

## Variants

Five variants cover the standard status spectrum plus the HBD-specific
`sage-advice` advisory tone.

## Dismissible

Set `dismissible` to render a dismiss button. Clicking it collapses the callout
and, once the transition ends, fires `onDismiss`. Dismissal can be controlled
via `dismissed` / `onDismissedChange` or left uncontrolled with
`defaultDismissed`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <CalloutDismissibleDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    'use client';

    import * as React from 'react';
    import { Callout } from '@/components/ui/callout';

    export function CalloutDismissibleDemo() {
      const [dismissed, setDismissed] = React.useState(false);

      if (dismissed) {
        return <Callout variant="info">Message dismissed.</Callout>;
      }

      return (
        <Callout
          variant="warning"
          title="Uncharted waters ahead"
          dismissible
          onDismiss={() => setDismissed(true)}
        >
          Your voyage strays beyond the mapped coastline.
        </Callout>
      );
    }
    ```

  </Tab>
</Tabs>
