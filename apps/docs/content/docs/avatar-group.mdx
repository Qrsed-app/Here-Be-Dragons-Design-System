`AvatarGroup` composes `Avatar` children into an overlapping stack. It renders
the first `max` avatars and appends a `+N` overflow bubble for the rest. The
host is a `role="group"` with a default `aria-label` reporting the total count.

## Basic

A group of avatars. With `max` (default `5`) or fewer children, no overflow
bubble is shown.

## Overflow

When the number of avatars exceeds `max`, the extras collapse into a `+N`
bubble. Set `max` to control how many are visible.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <AvatarGroupOverflowDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <AvatarGroup max={3}>
      <Avatar name="Ada Lovelace" />
      <Avatar name="Alan Turing" />
      <Avatar name="Grace Hopper" />
      <Avatar name="Katherine Johnson" />
      <Avatar name="Margaret Hamilton" />
      <Avatar name="Dorothy Vaughan" />
    </AvatarGroup>
    ```
  </Tab>
</Tabs>

## Sizes

The `size` prop is propagated to every child avatar and to the overflow bubble,
overriding each child's own size. Valid sizes: `xs`, `sm`, `md`, `lg`, `xl`,
`2xl`.

## With images

Children may carry an `imgSrc`; on load error they fall back to the generic
avatar icon.
