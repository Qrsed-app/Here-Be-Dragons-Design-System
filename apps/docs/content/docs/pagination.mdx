The HBD pagination is the `nav` landmark itself (`role="navigation"` +
`aria-label`). It is controlled-first — pass `page` + `onPageChange` to own the
state, or `defaultPage` to let it manage its own. Boundary prev/next stay
focusable with `aria-disabled` so keyboard users still discover the edge.

## Variants

The default `full` variant shows numbered pages with prev/next and ellipsis
gaps. `compact` reduces to prev/next around a live "Page N of M" label, and
`simple` is arrow-only.

## First / last and siblings

`showFirstLast` adds jump-to-edge buttons. `siblings` controls how many page
numbers appear either side of the current page.

## Link mode

Set `hrefPrefix` to render items as real `<a href>` anchors instead of buttons.
The current page becomes a `<span aria-current="page">`. This is static and
needs no client state.

## Controlled

Own the current page in React via `page` + `onPageChange`. The `onChange`
callback is also available and carries `{ page, total }`.

## Toolbar

The `full` variant grows a toolbar when you add `showGoto`, `totalRecords`, or a
`pageSize` + `pageSizeOptions` pair. The page-size select reuses the HBD select;
changing it resets the page to 1 and fires `onPageSizeChange`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <PaginationToolbarDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [page, setPage] = React.useState(1);
    const [pageSize, setPageSize] = React.useState(20);
    const totalRecords = 248;
    const total = Math.max(1, Math.ceil(totalRecords / pageSize));

    <Pagination
      page={page}
      total={total}
      totalRecords={totalRecords}
      pageSize={pageSize}
      pageSizeOptions={[10, 20, 50, 100]}
      showGoto
      onPageChange={setPage}
      onPageSizeChange={({ pageSize: next }) => {
        setPageSize(next);
        setPage(1);
      }}
    />
    ```

  </Tab>
</Tabs>
