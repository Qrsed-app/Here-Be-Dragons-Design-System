`StepperNav` renders a row (or column) of numbered step indicators joined by
connectors. Each step is `completed`, `active`, `upcoming`, or an explicit
`error` override — derived automatically from `activeStep` unless you set a
status yourself. Provide steps with the `steps` prop or as `<StepperNavStep>`
children.

## Variants

The `variant` prop switches between `horizontal` (default) and `vertical`
layouts.

## States

A step's status is normally inferred from `activeStep`, but you can force one
with the `status` prop on a `<StepperNavStep>` (or the matching `steps[]`
entry). Use `error` to flag a step that failed validation.

## Usage

In `non-linear` mode, completed and error indicators render as real buttons.
Drive the flow yourself with `activeStep` + `onStepChange` to let users jump
back to an earlier step. Click a completed step below to move the active index.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <StepperNavControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import * as React from 'react';
    import {
      StepperNav,
      type StepChangeDetail,
    } from '@/components/ui/stepper-nav';

    function Wizard() {
      const [active, setActive] = React.useState(2);

      return (
        <StepperNav
          mode="non-linear"
          steps={steps}
          activeStep={active}
          onStepChange={(detail: StepChangeDetail) => setActive(detail.step)}
        />
      );
    }
    ```

  </Tab>
</Tabs>
