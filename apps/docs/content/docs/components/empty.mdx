## Installation

```bash
npx shadcn@latest add @hbd/empty
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/empty.json
```

## Usage

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty";
```

```tsx
<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon">
      <Icon />
    </EmptyMedia>
    <EmptyTitle>No data</EmptyTitle>
    <EmptyDescription>No data found</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button>Add data</Button>
  </EmptyContent>
</Empty>
```

An `<svg>` in the default `EmptyMedia` is drawn as a faded ink illustration, 64px unless it has a
`size-*` class of its own.

## API Reference

### EmptyMedia

<TypeTable
  type={{
    variant: {
      type: '"default" | "icon"',
      default: '"default"',
      description:
        "`default` draws a direct `<svg>` child as a faded illustration; `icon` frames a small icon.",
    },

Every other prop is forwarded to the `<div>` each part renders.
