## Installation

```bash
npx shadcn@latest add @hbd/avatar
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/avatar.json
```

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
```

```tsx
<Avatar>
  <AvatarImage src="https://i.pravatar.cc/96?img=5" alt="Ada Lovelace" />
  <AvatarFallback>AL</AvatarFallback>
</Avatar>
```

### Avatar Group Count

Show the first few people and put the rest in an `AvatarGroupCount`, last in the group. It takes the
size of the avatars around it.

        <Avatar>
          <AvatarFallback>AL</AvatarFallback>
        </Avatar>
        <Avatar>
          <AvatarFallback>AT</AvatarFallback>
        </Avatar>
        <Avatar>
          <AvatarFallback>GH</AvatarFallback>
        </Avatar>
        <AvatarGroupCount aria-label="3 more">+3</AvatarGroupCount>
      </AvatarGroup>
      <AvatarGroup>
        <Avatar size="lg">
          <AvatarFallback>AL</AvatarFallback>
        </Avatar>
        <Avatar size="lg">
          <AvatarFallback>AT</AvatarFallback>
        </Avatar>
        <AvatarGroupCount>
          <PlusIcon />
        </AvatarGroupCount>
      </AvatarGroup>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { PlusIcon } from "lucide-react";

    const people = [
      { name: "Ada Lovelace", initials: "AL" },
      { name: "Alan Turing", initials: "AT" },
      { name: "Grace Hopper", initials: "GH" },
      // …three more
    ];
    const max = 3;

    <AvatarGroup role="group" aria-label={`${people.length} participants`}>
      {people.slice(0, max).map((person) => (
        <Avatar key={person.name}>
          <AvatarFallback>{person.initials}</AvatarFallback>
        </Avatar>
      ))}
      {people.length > max && (
        <AvatarGroupCount aria-label={`${people.length - max} more`}>
          +{people.length - max}
        </AvatarGroupCount>
      )}
    </AvatarGroup>

    <AvatarGroup>
      <Avatar size="lg">
        <AvatarFallback>AL</AvatarFallback>
      </Avatar>
      <Avatar size="lg">
        <AvatarFallback>AT</AvatarFallback>
      </Avatar>
      <AvatarGroupCount>
        <PlusIcon />
      </AvatarGroupCount>
    </AvatarGroup>
    ```

## API Reference

### Avatar

<TypeTable
  type={{
    size: {
      type: '"default" | "xs" | "sm" | "lg" | "xl" | "2xl"',
      default: '"default"',
      description:
        "24px (`xs`) to 80px (`2xl`); `default` is 40px. `xs`, `xl` and `2xl` are Here Be Dragons additions.",
    },
  }}
/>

Every other prop goes to the Radix Avatar root. `AvatarImage` and `AvatarFallback` take the Radix
Image and Fallback props (`src`, `alt`, `onLoadingStatusChange`, `delayMs`) — see
[Radix Avatar](https://www.radix-ui.com/primitives/docs/components/avatar). `AvatarBadge` renders a
`<span>`, `AvatarGroup` and `AvatarGroupCount` a `<div>`; they take that element's props.
