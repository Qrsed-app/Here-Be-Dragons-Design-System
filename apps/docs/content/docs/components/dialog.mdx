## Installation

```bash
npx shadcn@latest add @hbd/dialog
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/dialog.json
```

## Usage

```tsx
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@/components/ui/dialog";
```

```tsx
<Dialog>
  <DialogTrigger>Open</DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>Are you absolutely sure?</DialogTitle>
      <DialogDescription>
        This action cannot be undone. This will permanently delete your chart.
      </DialogDescription>
    </DialogHeader>
  </DialogContent>
</Dialog>
```

Content placed after `DialogHeader` is the dialog body: it gets the body padding and type, and the
header and footer rule it off above and below.

### Size

Here Be Dragons addition — `size` on `DialogContent` sets the width: `sm` (400px), `default`
(560px), `lg` (720px) or `full` (the whole viewport).

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <DialogSizesDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    {(["sm", "default", "lg", "full"] as const).map((size) => (
      <Dialog key={size}>
        <DialogTrigger asChild>
          <Button variant="secondary">{size}</Button>
        </DialogTrigger>
        <DialogContent size={size} aria-describedby={undefined}>
          <DialogHeader>
            <DialogTitle>{size} dialog</DialogTitle>
          </DialogHeader>
          <p>This dialog uses the {size} width.</p>
        </DialogContent>
      </Dialog>
    ))}
    ```

## API Reference

### DialogContent

<TypeTable
  type={{
    showCloseButton: {
      type: "boolean",
      default: "true",
      description: "Render the close button in the top-right corner of the header.",
    },
    size: {
      type: '"sm" | "default" | "lg" | "full"',
      default: '"default"',
      description:
        "Dialog width: 400px, 560px, 720px or the whole viewport. Here Be Dragons addition.",
    },
  }}
/>

Every other prop goes to Radix `Dialog.Content`. `DialogContent` renders the portal and overlay
for you.

### DialogFooter

<TypeTable
  type={{
    showCloseButton: {
      type: "boolean",
      default: "false",
      description: "Append an outline Close button that closes the dialog.",
    },
  }}
/>

`Dialog`, `DialogTrigger`, `DialogClose`, `DialogTitle`, `DialogDescription`, `DialogPortal` and
`DialogOverlay` take the props of their [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog)
parts. `DialogHeader` and `DialogFooter` render a `<div>`.
