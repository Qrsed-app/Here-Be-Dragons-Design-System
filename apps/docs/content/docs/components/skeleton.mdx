## Installation

```bash
npx shadcn@latest add @hbd/skeleton
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/skeleton.json
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton";
```

```tsx
<Skeleton className="h-[1.0625rem] w-[250px]" />
```

The skeleton is a parchment block with a shimmer sweeping across it. Size and shape come from
`className`. Put `aria-busy` and a label on the container that will hold the real content, not on
the skeletons.

### Without shimmer

The shimmer is on by default and freezes under `prefers-reduced-motion`. Add `after:hidden` for a
static placeholder, for example when many skeletons would animate at once.

## API Reference

`Skeleton` has no props of its own: it renders a `<div>` and forwards every prop to it. Pass the
size and shape as `className`.
