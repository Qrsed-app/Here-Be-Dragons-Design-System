Collapsible ships unstyled, exactly as upstream — it contributes the open/close behaviour and the
`data-state` hooks, and the Here Be Dragons look comes from what you compose inside it.

## Installation

```bash
npx shadcn@latest add @hbd/collapsible
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/collapsible.json
```

## Usage

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@/components/ui/collapsible";
```

```tsx
<Collapsible>
  <CollapsibleTrigger>Can you keep a secret?</CollapsibleTrigger>
  <CollapsibleContent>Yes. Free to use for personal and commercial projects.</CollapsibleContent>
</Collapsible>
```

## API Reference

Every part takes the props of its Radix counterpart — see
[Radix Collapsible](https://www.radix-ui.com/primitives/docs/components/collapsible): `open`,
`defaultOpen`, `onOpenChange` and `disabled` on `Collapsible`, `asChild` on `CollapsibleTrigger`,
and `forceMount` on `CollapsibleContent`.
