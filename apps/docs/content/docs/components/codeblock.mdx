Here Be Dragons component — shadcn/ui has no counterpart. It follows the shadcn conventions: one
named export per part, a `data-slot` on each, and `className` merged last. The copy button is the
[Button](/docs/components/button) component.

## Installation

```bash
npx shadcn@latest add @hbd/codeblock
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/codeblock.json
```

## Usage

```tsx
import {
  Codeblock,
  CodeblockCode,
  CodeblockContent,
  CodeblockCopyButton,
  CodeblockFilename,
  CodeblockHeader,
  CodeblockLanguage,
  CodeblockLineNumbers,
} from "@/components/ui/codeblock";
```

```tsx
<Codeblock>
  <CodeblockContent>
    <CodeblockCode>{code}</CodeblockCode>
    <CodeblockCopyButton value={code} />
  </CodeblockContent>
</Codeblock>
```

the output of any highlighter that emits those classes.

## API Reference

### CodeblockLineNumbers

<TypeTable
  type={{
    count: {
      type: "number",
      description: "How many line numbers to render. Match the number of lines in the code.",
    },
  }}
/>

Renders an `aria-hidden` `<div>`; other props go to it.

### CodeblockCopyButton

<TypeTable
  type={{
    value: {
      type: "string",
      description: "Text written to the clipboard.",
    },
  }}
/>

A [Button](/docs/components/button) pinned to the top-right of `CodeblockContent`. It reads Copy,
then Copied or Failed for two seconds, with a matching `aria-label` and `data-state`
(`idle` | `copied` | `failed`). Other props go to the Button; calling `event.preventDefault()` in
your `onClick` skips the copy.

### CodeblockCode

Renders `<pre><code>`; props and `className` go to the `<code>`. Token classes and their colours:

| Class                          | Colour                   |
| ------------------------------ | ------------------------ |
| `tok-keyword`, `tok-selector`  | `syntax-keyword`         |
| `tok-string`, `tok-value`      | `syntax-string`          |
| `tok-comment`                  | `syntax-comment`, italic |
| `tok-number`                   | `syntax-number`          |
| `tok-function`, `tok-property` | `syntax-function`        |
| `tok-operator`                 | `syntax-operator`        |

### Other parts

`Codeblock`, `CodeblockHeader` and `CodeblockContent` render `<div>`s; `CodeblockFilename` and
`CodeblockLanguage` render `<span>`s. Each forwards its props. Give a block with a header
`role="region"` and an `aria-label` so it is reachable as a landmark.
