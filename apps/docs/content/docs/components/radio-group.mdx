## Installation

```bash
npx shadcn@latest add @hbd/radio-group
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/radio-group.json
```

## Usage

```tsx
import { Field, FieldLabel } from "@/components/ui/field";
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group";
```

```tsx
<RadioGroup defaultValue="option-one">
  <Field orientation="horizontal" className="items-start gap-2">
    <RadioGroupItem value="option-one" id="option-one" />
    <FieldLabel htmlFor="option-one">Option One</FieldLabel>
  </Field>
  <Field orientation="horizontal" className="items-start gap-2">
    <RadioGroupItem value="option-two" id="option-two" />
    <FieldLabel htmlFor="option-two">Option Two</FieldLabel>
  </Field>
</RadioGroup>
```

The `FieldSet` gap and `FieldLegend` overrides in the examples give the body-size, semibold legend and
spacing of the Here Be Dragons radio group.

## API Reference

`RadioGroup` and `RadioGroupItem` add no props of their own. `value`, `defaultValue`, `onValueChange`,
`orientation`, `disabled`, `required` and `name` go to the Radix RadioGroup root; `value` and `disabled`
to each item. `aria-invalid` on either shows the red rings. See the
[Radix Radio Group documentation](https://www.radix-ui.com/primitives/docs/components/radio-group).
