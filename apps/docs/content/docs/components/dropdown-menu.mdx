## Installation

```bash
npx shadcn@latest add @hbd/dropdown-menu
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/dropdown-menu.json
```

## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";
```

```tsx
<DropdownMenu>
  <DropdownMenuTrigger>Open</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuItem>Profile</DropdownMenuItem>
    <DropdownMenuItem>Billing</DropdownMenuItem>
    <DropdownMenuItem>Team</DropdownMenuItem>
    <DropdownMenuItem>Subscription</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## Examples

### Basic

`onSelect` on an item runs its action; the menu closes afterwards. `align="start"` lines the panel up
with the trigger's left edge, as the Here Be Dragons menu always did — the Radix default is `center`.

    <div className="flex flex-col items-start gap-3">
      <DropdownMenu>
        <DropdownMenuTrigger asChild>
          <Button variant="secondary">Actions</Button>
        </DropdownMenuTrigger>
        <DropdownMenuContent align="start">
          <DropdownMenuItem onSelect={() => setLast("Edit quest")}>Edit quest</DropdownMenuItem>

    </div>

### Groups and Labels

`DropdownMenuLabel` is the uppercase, letter-spaced heading of a `DropdownMenuGroup`. Separate
sections with `DropdownMenuSeparator`; two groups placed directly next to each other are ruled off
automatically. Disabled items are skipped by keyboard navigation.

## API Reference

### DropdownMenuContent

<TypeTable
  type={{
    sideOffset: {
      type: "number",
      default: "4",
      description: "Gap in px between the trigger and the panel.",
    },
    align: {
      type: '"start" | "center" | "end"',
      default: '"center"',
      description:
        "Alignment against the trigger. Use `start` for the classic Here Be Dragons placement.",
    },
  }}
/>

The panel is between 160px and 280px wide unless you set a width, and scrolls past 320px of height.

### DropdownMenuItem

<TypeTable
  type={{
    variant: {
      type: '"default" | "destructive"',
      default: '"default"',
      description: "`destructive` writes the item in blood and tints its highlight.",
    },
    inset: {
      type: "boolean",
      default: "false",
      description: "Indent the item to align with items that have an icon.",
    },
  }}
/>

### DropdownMenuLabel and DropdownMenuSubTrigger

<TypeTable
  type={{
    inset: {
      type: "boolean",
      default: "false",
      description: "Indent to align with items that have an icon.",
    },
  }}
/>

Every other prop goes to the matching part of [Radix Dropdown Menu](https://www.radix-ui.com/primitives/docs/components/dropdown-menu)
(`DropdownMenu` → `Root`, `DropdownMenuItem` → `Item`, and so on). `DropdownMenuShortcut` renders a
`<span>`.
