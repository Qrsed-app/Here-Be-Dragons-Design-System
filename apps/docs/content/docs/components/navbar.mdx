A Here Be Dragons component — shadcn/ui has no counterpart. It is a layout shell: the links are a
[Navigation Menu](/docs/components/navigation-menu) and the small-screen menu is a
[Sheet](/docs/components/sheet), so the behaviour comes from parts you already have.

Resize the window below the `md` breakpoint to swap the centred links for the menu button.

## Installation

```bash
npx shadcn@latest add @hbd/navbar
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/navbar.json
```

Navigation Menu and Sheet come with it.

## Usage

```tsx
import {
  Navbar,
  NavbarActions,
  NavbarInner,
  NavbarLink,
  NavbarLogo,
  NavbarMobileActions,
  NavbarMobileLink,
  NavbarMobileNav,
  NavbarNav,
} from "@/components/ui/navbar";
```

```tsx
<Navbar sticky>
  <NavbarInner>
    <NavbarLogo>
      <a href="/">Here Be Dragons</a>
    </NavbarLogo>
    <NavbarNav>{/* NavigationMenu */}</NavbarNav>
    <NavbarActions>{/* buttons, and the Sheet trigger */}</NavbarActions>
  </NavbarInner>
</Navbar>
```

`NavbarInner` centres the bar in a `68.75rem` container. `NavbarNav` hides itself below the `md`
breakpoint, which is where the Sheet takes over — give its trigger `className="md:hidden"` so
exactly one of the two is visible at any width.

## Examples

### Variants

`sticky` pins the bar to the top of the viewport. `bordered` swaps the drop shadow for a hairline
rule, and `transparent` drops both so the bar can sit over a hero image.

### The other parts

`NavbarInner` (`div`) is the centred container; `NavbarLogo` (`div`) sets the display type and
styles any `<a>` inside it; `NavbarNav` (`div`) holds the Navigation Menu and hides below `md`;
`NavbarActions` (`div`) is the right-hand cluster. `NavbarLink` is a
`NavigationMenuLink` with the bar's link chrome — pass `active` to mark the current page.
`NavbarMobileNav` (`nav`), `NavbarMobileLink` (`a`, mark it `aria-current="page"`) and
`NavbarMobileActions` (`div`) dress the inside of the Sheet.
