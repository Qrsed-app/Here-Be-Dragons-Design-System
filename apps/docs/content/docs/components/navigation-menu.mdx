## Installation

```bash
npx shadcn@latest add @hbd/navigation-menu
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/navigation-menu.json
```

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@/components/ui/navigation-menu";
```

```tsx
<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Item One</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink>Link</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

A plain link needs the trigger's padding to sit level with its neighbours — `className="px-3 py-2"`,
as above.

## API Reference

### NavigationMenu

<TypeTable
  type={{
    viewport: {
      type: "boolean",
      default: "true",
      description:
        "Render the shared viewport panel that every NavigationMenuContent animates into. `false` anchors each panel under its own trigger.",
    },
  }}
/>

Every other prop — `value`, `defaultValue`, `onValueChange`, `delayDuration`, `orientation` — goes
to Radix. `NavigationMenuLink` takes `active` and `asChild`. See
[Radix Navigation Menu](https://www.radix-ui.com/primitives/docs/components/navigation-menu).

The exported `navigationMenuTriggerStyle()` returns the trigger's classes, for a link that has to
match a trigger exactly.
