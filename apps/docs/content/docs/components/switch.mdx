## Installation

```bash
npx shadcn@latest add @hbd/switch
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/switch.json
```

## Usage

```tsx
import { Switch } from "@/components/ui/switch";
```

```tsx
<Switch />
```

In a horizontal `Field`, `items-start py-3` keeps the switch level with the first line of the label and
the tap area at least 44px tall; the body-size label matches the other choice controls.
