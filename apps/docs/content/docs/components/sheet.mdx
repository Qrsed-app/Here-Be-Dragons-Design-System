## Installation

```bash
npx shadcn@latest add @hbd/sheet
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/sheet.json
```

## Usage

```tsx
import {
  Sheet,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@/components/ui/sheet";
```

```tsx
<Sheet>
  <SheetTrigger>Open</SheetTrigger>
  <SheetContent>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>
        This action cannot be undone. This will permanently delete your chart.
      </SheetDescription>
    </SheetHeader>
  </SheetContent>
</Sheet>
```

Content between `SheetHeader` and `SheetFooter` is the body: it gets the body padding and type, and
the footer sits at the bottom edge.

### Wide and tall

Here Be Dragons addition — `wide` widens a left or right sheet from 320px to 480px; `tall` raises a
top or bottom sheet from 50% to 80% of the viewport. Each is ignored on the other axis.

### Without overlay

Here Be Dragons addition — `showOverlay={false}` drops the scrim, for a sidebar. To keep the page
behind usable, also set `modal={false}` on `Sheet` and stop outside clicks from closing it.

  <Tab value="Code">
    ```tsx

      <SheetTrigger asChild>
        <Button variant="secondary">Open sidebar</Button>
      </SheetTrigger>
      <SheetContent
        side="left"
        showOverlay={false}
        aria-describedby={undefined}
        onInteractOutside={(event) => event.preventDefault()}
      >
        <SheetHeader>
          <SheetTitle>Navigation</SheetTitle>
        </SheetHeader>
        <p>No scrim, and the page behind stays usable. Close it with the button or Escape.</p>
      </SheetContent>
    </Sheet>
    ```

### Close button

`showCloseButton={false}` hides the corner button. Escape still closes the sheet; to make it
undismissable, also prevent `onEscapeKeyDown` and `onInteractOutside`.

## API Reference

### SheetContent

<TypeTable
  type={{
    side: {
      type: '"top" | "right" | "bottom" | "left"',
      default: '"right"',
      description: "The edge the sheet slides in from.",
    },
    showCloseButton: {
      type: "boolean",
      default: "true",
      description: "Render the close button in the top-right corner.",
    },
    showOverlay: {
      type: "boolean",
      default: "true",
      description: "Render the scrim behind the sheet. Here Be Dragons addition.",
    },
    wide: {
      type: "boolean",
      default: "false",
      description: "480px instead of 320px for left and right sheets. Here Be Dragons addition.",
    },
    tall: {
      type: "boolean",
      default: "false",
      description: "80vh instead of 50vh for top and bottom sheets. Here Be Dragons addition.",
    },
  }}
/>

Every other prop goes to Radix `Dialog.Content`. `SheetContent` renders the portal and overlay for
you. `Sheet`, `SheetTrigger`, `SheetClose`, `SheetTitle` and `SheetDescription` take the props of
their [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog) parts;
`SheetHeader` and `SheetFooter` render a `<div>`.
