## Installation

```bash
npx shadcn@latest add @hbd/card
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/card.json
```

## Usage

```tsx
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";
```

```tsx
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
    <CardAction>Card Action</CardAction>
  </CardHeader>
  <CardContent>
    <p>Card Content</p>
  </CardContent>
  <CardFooter>
    <p>Card Footer</p>
  </CardFooter>
</Card>
```

### Interactive

Here Be Dragons addition — `interactive` lifts the card on hover and draws the focus ring outside it.
Render a link with `asChild`; for a card that runs code instead, keep the `<div>` and add
`role="button"`, `tabIndex={0}` and your click and Enter / Space handlers.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>

            <CardTitle>Eastern Sea Route</CardTitle>
            <CardDescription>Opens the chart</CardDescription>
          </CardHeader>
          <CardContent>Three days under full sail.</CardContent>

## API Reference

### Card

<TypeTable
  type={{
    size: {
      type: '"default" | "sm" | "lg" | "flush"',
      default: '"default"',
      description: "Padding of the card and every part. Here Be Dragons addition.",
    },
    variant: {
      type: '"default" | "bordered" | "elevated"',
      default: '"default"',
      description:
        "Surface: hairline border with a light shadow, a heavier border without shadow, or a deeper shadow. Here Be Dragons addition.",
    },
    interactive: {
      type: "boolean",
      default: "false",
      description:
        "Hover lift, pointer cursor and an outside focus ring. Here Be Dragons addition.",
    },
    asChild: {
      type: "boolean",
      default: "false",
      description:
        "Render the single child element (e.g. a link) instead of a `<div>` (Radix Slot). Here Be Dragons addition.",
    },
  }}
/>

Every other prop is forwarded to the `<div>` — or to the child when `asChild` is set.
`CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent` and `CardFooter` render a
`<div>` and take its props. The exported `cardVariants` helper returns the root classes.
