## Installation

```bash
npx shadcn@latest add @hbd/alert
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/alert.json
```

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";
```

```tsx
<Alert variant="info">
  <InfoIcon />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app using the cli.</AlertDescription>
</Alert>
```

An `<svg>` as the first child becomes the 16px icon beside the text.

### Dismissible

Put the close button in an `AlertAction`, which sits at the end of the first line. The Here Be
Dragons dismiss is a 48px target in the alert's own colour.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <AlertDismissibleDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    "use client";

    import * as React from "react";

    import { Alert, AlertAction, AlertDescription, AlertTitle } from "@/components/ui/alert";
    import { Button } from "@/components/ui/button";

    export function AlertDismissibleDemo() {
      const [open, setOpen] = React.useState(true);

      if (!open) {
        return (
          <Button variant="secondary" size="sm" onClick={() => setOpen(true)}>
            Restore notice
          </Button>
        );
      }

      return (
        <Alert variant="success" className="w-full">
          <svg
            viewBox="0 0 16 16"
            fill="none"
            stroke="currentColor"
            strokeWidth="1.6"
            strokeLinecap="round"
            strokeLinejoin="round"
            aria-hidden="true"
          >
            <circle cx="8" cy="8" r="6.5" />
            <polyline points="5,8.5 7.2,10.6 11,6.5" />
          </svg>
          <AlertTitle>Voyage logged</AlertTitle>
          <AlertDescription>Your chart has been saved to the ship&apos;s ledger.</AlertDescription>
          <AlertAction>
            <Button
              variant="ghost"
              size="icon-sm"
              aria-label="Dismiss"
              onClick={() => setOpen(false)}
              className="size-12 border-0 text-current opacity-80 hover:bg-transparent hover:text-current hover:opacity-100 focus-visible:outline-current"
            >
              <svg
                viewBox="0 0 16 16"
                fill="none"
                stroke="currentColor"
                strokeWidth="1.8"
                strokeLinecap="round"
                aria-hidden="true"
              >
                <line x1="4" y1="4" x2="12" y2="12" />
                <line x1="12" y1="4" x2="4" y2="12" />
              </svg>
            </Button>
          </AlertAction>
        </Alert>
      );
    }
    ```

  </Tab>

## API Reference

### Alert

<TypeTable
  type={{

      type: '"default" | "destructive" | "info" | "success" | "warning" | "error" | "sage-advice"',
      default: '"default"',

    },
    layout: {
      type: '"default" | "banner" | "inline"',

        "`banner` is a sticky full-width bar, `inline` a compact note. Here Be Dragons addition.",
    },
  }}

`Alert` renders a `<div role="alert">`; override `role` (e.g. `role="status"`) for messages that
should not interrupt. `AlertTitle`, `AlertDescription` and `AlertAction` render a `<div>`, `AlertIcon`
an `aria-hidden` `<span>` (both Here Be Dragons additions); each takes its element's props.
