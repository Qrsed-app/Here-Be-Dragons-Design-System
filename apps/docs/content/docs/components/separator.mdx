## Installation

```bash
npx shadcn@latest add @hbd/separator
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/separator.json
```

## Usage

```tsx
import { Separator } from "@/components/ui/separator";
```

```tsx
<Separator />
```

## Examples

### Spacing

Unlike upstream, the separator keeps the Here Be Dragons page rhythm: a horizontal rule carries
`my-6` (24px above and below) and a vertical rule `mx-2`, one `1em` tall. Pass your own margin to
change it, or `my-0` / `mx-0` to remove it.

Here Be Dragons addition — `subtle`, `strong` and `gold` rules. Separators are decorative, so the
lighter tokens are intentional.

### Ornamental

Here Be Dragons addition — a gold sigil between two fading rules, for breaking up long-form
parchment text. It uses a larger `my-8` rhythm and is hidden from assistive technology.
