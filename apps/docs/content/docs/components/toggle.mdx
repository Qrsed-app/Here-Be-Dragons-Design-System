## Installation

```bash
npx shadcn@latest add @hbd/toggle
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/toggle.json
```

## Usage

```tsx
import { Toggle } from "@/components/ui/toggle";
```

```tsx
<Toggle>Toggle</Toggle>
```

Off, a toggle looks like a secondary `Button`; on, it turns crimson.

`pressed`, `defaultPressed`, `onPressedChange`, `disabled` and every other prop go to the Radix Toggle
root. See the [Radix Toggle documentation](https://www.radix-ui.com/primitives/docs/components/toggle).
The exported `toggleVariants` helper returns the same classes.
