## Installation

```bash
npx shadcn@latest add @hbd/alert-dialog
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/alert-dialog.json
```

## Usage

```tsx
import {
  AlertDialog,
  AlertDialogAction,
  AlertDialogCancel,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogHeader,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@/components/ui/alert-dialog";
```

```tsx
<AlertDialog>
  <AlertDialogTrigger>Open</AlertDialogTrigger>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Are you absolutely sure?</AlertDialogTitle>
      <AlertDialogDescription>
        This action cannot be undone. This will permanently delete your chart.
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>Continue</AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

The title is ruled off from the description, which reads as the dialog's message. Radix focuses
`AlertDialogCancel` when the dialog opens; Escape cancels, but an outside click does nothing, so
the reader has to choose.

## API Reference

### AlertDialogContent

<TypeTable
  type={{
    size: {
      type: '"default" | "sm"',
      default: '"default"',
      description: "Dialog width: 560px or 400px.",
    },
  }}
/>

Every other prop goes to Radix `AlertDialog.Content`; it renders the portal and overlay for you.

### AlertDialogAction and AlertDialogCancel

<TypeTable
  type={{
    variant: {
      type: '"default" | "destructive" | "outline" | "secondary" | "ghost" | "link" | "gold"',
      default: '"default" (Action), "outline" (Cancel)',
      description: "Button variant.",
    },
    size: {
      type: '"default" | "sm" | "lg" | "icon" | "icon-sm" | "icon-lg"',
      default: '"default"',
      description: "Button size.",
    },
  }}
/>

The remaining parts take the props of their
[Radix Alert Dialog](https://www.radix-ui.com/primitives/docs/components/alert-dialog) parts;
`AlertDialogHeader`, `AlertDialogFooter` and `AlertDialogMedia` render a `<div>`.
