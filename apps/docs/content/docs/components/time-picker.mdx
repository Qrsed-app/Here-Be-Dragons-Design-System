A Here Be Dragons component: shadcn/ui has no time picker. It is composed the way Select is — a
root that owns the value, a trigger, a value, and the panel.

## Installation

```bash
npx shadcn@latest add @hbd/time-picker
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/time-picker.json
```

## Usage

```tsx
import {
  TimePicker,
  TimePickerContent,
  TimePickerTrigger,
  TimePickerValue,
} from "@/components/ui/time-picker";
```

```tsx
<TimePicker defaultValue="09:30">
  <TimePickerTrigger aria-label="Departure time">
    <TimePickerValue />
  </TimePickerTrigger>
  <TimePickerContent />
</TimePicker>
```

The value is always an `HH:MM` string on a 24-hour clock, whatever the panel displays. Picking an
hour and a minute only stages them: **Confirm** commits the value and closes the panel, **Cancel**,
Escape and an outside click discard the staged selection, and **Clear** empties it without closing.
The two numbers in the panel header can be clicked and typed into.

## API Reference

### TimePicker

<TypeTable
  type={{
    value: {
      type: "string",
      description: "Controlled `HH:MM` value on a 24-hour clock. Empty string means no time.",
    },
    defaultValue: {
      type: "string",
      default: '""',
      description: "Uncontrolled initial value.",
    },
    onValueChange: {
      type: "(value: string) => void",
      description: "Called when Confirm commits a new value.",
    },
    format: {
      type: '"12" | "24"',
      default: '"24"',
      description: "Panel and trigger display. The value stays 24-hour either way.",
    },
    minuteStep: {
      type: "number",
      default: "1",
      description: "Interval between the minutes listed in the minute column.",
    },
    disabled: {
      type: "boolean",
      default: "false",
      description: "Disables the trigger so the panel cannot open.",
    },
    name: {
      type: "string",
      description: "Renders a hidden input with the value, for plain form posts.",
    },
  }}
/>

`open`, `defaultOpen`, `onOpenChange` and `modal` are forwarded to the underlying
[Popover](/docs/components/popover) root.

### TimePickerTrigger

Renders the `<button>` that opens the panel, with the caret; takes every button prop. Give it an
`aria-label` or an `id` tied to a `FieldLabel`, and `aria-invalid` for the error border.

### TimePickerValue

<TypeTable
  type={{
    placeholder: {
      type: "string",
      default: '"Select the hour…"',
      description: "Shown when no time is set; it carries `data-placeholder` for styling.",
    },
  }}
/>

### TimePickerContent

The panel: header, hour and minute columns, the AM·PM column in 12-hour format, and the footer. It
takes [PopoverContent](/docs/components/popover) props, so `align`, `side`, `sideOffset` and
`className` all work.
