## Installation

```bash
npx shadcn@latest add @hbd/menubar
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/menubar.json
```

## Usage

```tsx
import {
  Menubar,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarSeparator,
  MenubarShortcut,
  MenubarTrigger,
} from "@/components/ui/menubar";
```

```tsx
<Menubar>
  <MenubarMenu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>
        New Tab <MenubarShortcut>⌘T</MenubarShortcut>
      </MenubarItem>
      <MenubarItem>New Window</MenubarItem>
      <MenubarSeparator />
      <MenubarItem>Share</MenubarItem>
      <MenubarSeparator />
      <MenubarItem>Print</MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

The open trigger is underlined in gold. Its menus use the panel, items, labels and destructive
styling of the [Dropdown Menu](/docs/components/dropdown-menu).

## API Reference

### MenubarContent

<TypeTable
  type={{

### MenubarItem

<TypeTable
  type={{
    variant: {
      type: '"default" | "destructive"',
      default: '"default"',
      description: "`destructive` writes the item in blood and tints its highlight.",
    },
    inset: {
      type: "boolean",
      default: "false",
      description: "Indent the item to align with items that have an icon.",
    },
  }}
/>

`MenubarLabel` and `MenubarSubTrigger` take the same `inset` prop. Every other prop goes to the
matching part of [Radix Menubar](https://www.radix-ui.com/primitives/docs/components/menubar);
`MenubarShortcut` renders a `<span>`.
