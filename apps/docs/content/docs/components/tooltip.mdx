## Installation

```bash
npx shadcn@latest add @hbd/tooltip
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/tooltip.json
```

## Usage

Wrap the app (or the part that uses tooltips) in one `TooltipProvider`.

```tsx
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@/components/ui/tooltip";
```

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>Hover</TooltipTrigger>
    <TooltipContent>
      <p>Add to library</p>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## API Reference

### TooltipContent

<TypeTable
  type={{
    sideOffset: {
      type: "number",
      default: "8",
      description: "Gap in px between trigger and bubble. The arrow sits in the gap.",
    },
  }}

Every other prop goes to Radix `Tooltip.Content`. `TooltipProvider` defaults `delayDuration` to
`0`; `Tooltip`, `TooltipTrigger` and `TooltipProvider` take the props of their
[Radix Tooltip](https://www.radix-ui.com/primitives/docs/components/tooltip) parts.
