Here Be Dragons component — shadcn/ui has no counterpart. It follows the shadcn conventions: one
named export per part, a `data-slot` on each, and `className` merged last.

## Installation

```bash
npx shadcn@latest add @hbd/spell-card
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/spell-card.json
```

## Usage

```tsx
import {
  SpellCard,
  SpellCardDescription,
  SpellCardFooter,
  SpellCardHigherLevels,
  SpellCardHigherLevelsLabel,
  SpellCardLevel,

  SpellCardMetaItem,
  SpellCardMetaLabel,
  SpellCardMetaValue,
  SpellCardSchool,
  SpellCardSeparator,
  SpellCardTag,
  SpellCardTags,
  SpellCardTitle,
} from "@/components/ui/spell-card";
```

```tsx
<SpellCard school="abjuration">
  <SpellCardLevel>Lvl 1</SpellCardLevel>
  <SpellCardSchool>Abjuration</SpellCardSchool>
  <SpellCardTitle>Shield</SpellCardTitle>
  <SpellCardSeparator />

</SpellCard>
```

## API Reference

### SpellCard

<TypeTable
  type={{
    school: {
      type: '"abjuration" | "conjuration" | "divination" | "enchantment" | "evocation" | "illusion" | "necromancy" | "transmutation"',
      default: '"evocation"',
      description: "Colours of the band, level badge and tags.",
    },
    selected: {
      type: "boolean",
      default: "false",
      description: "Gold border and offset shadow. Sets `data-selected`.",
    },
  }}
/>

Renders an `<article>` with the decorative band and corners; other props go to it. Give it an
`aria-label` such as `"Fireball spell card"`, and `tabIndex={0}` when cards are browsed with the
keyboard — the focus ring is built in. The school colours are the custom properties
`--spell-card-school`, `--spell-card-school-accent` and `--spell-card-school-foreground`; set them
in `className` for a colour outside the eight schools.

### Other parts

Each part forwards its props to the element it renders.

| Part                                                   | Element                                  |
| ------------------------------------------------------ | ---------------------------------------- |
| `SpellCardLevel`                                       | `<span>`, pinned to the top-right corner |
| `SpellCardSchool`                                      | `<div>`                                  |
| `SpellCardTags` / `SpellCardTag`                       | `<div>` / `<span>`                       |
| `SpellCardSeparator`                                   | `<hr>`, dashed                           |
| `SpellCardMeta` / `SpellCardMetaItem`                  | `<dl>` two-column grid / `<div>`         |
| `SpellCardMetaLabel` / `SpellCardMetaValue`            | `<dt>` / `<dd>`                          |
| `SpellCardDescription`                                 | `<p>`                                    |
| `SpellCardHigherLevels` / `SpellCardHigherLevelsLabel` | `<div>` / `<span>`                       |
| `SpellCardFooter`                                      | `<div>`                                  |
