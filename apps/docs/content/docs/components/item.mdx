## Installation

```bash
npx shadcn@latest add @hbd/item
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/item.json
```

## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item";
```

```tsx
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

A plain-text `ItemTitle` and every `ItemDescription` stay on one line and end in an ellipsis when
they run out of room. Add `whitespace-normal` to let them wrap.

### Link

blood bar on its leading edge. For a list flush with its container's text edge, remove the horizontal

### Selectable

Buttons as items, with `aria-current="true"` on the chosen one. The secondary line is a `span`,
not `ItemDescription`: that renders a `<p>`, which browsers reject inside a `<button>`. Use
`ItemDescription` on an `Item` that is not a button.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <ItemSelectableDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    "use client";

    import * as React from "react";

    import { Item, ItemContent, ItemGroup, ItemTitle } from "@/components/ui/item";

    const ports = [
      { value: "tortuga", name: "Tortuga", description: "Lawless free port" },
      { value: "nassau", name: "Nassau", description: "Pirate republic" },
      { value: "port-royal", name: "Port Royal", description: "Crown stronghold" },
    ];

    export function ItemSelectableDemo() {
      const [selected, setSelected] = React.useState("nassau");

      return (
        <ItemGroup
          role="group"
          aria-label="Home port"
          className="w-full max-w-md overflow-hidden rounded-lg border border-border-subtle"
        >
          {ports.map((port) => (
            <Item key={port.value} asChild>
              <button
                type="button"
                aria-current={selected === port.value ? "true" : undefined}
                onClick={() => setSelected(port.value)}
              >
                <ItemContent>
                  <ItemTitle>{port.name}</ItemTitle>
                  {/* Not ItemDescription: it renders a <p>, which is invalid inside a <button>. */}
                  <span className="font-sans text-[0.8125rem] leading-[1.35] text-muted-foreground">
                    {port.description}
                  </span>
                </ItemContent>
              </button>
            </Item>
          ))}
        </ItemGroup>
      );
    }
    ```

  </Tab>
</Tabs>

## API Reference

### Item

<TypeTable
  type={{
    variant: {
      type: '"default" | "outline" | "muted"',

    },
    size: {
      type: '"default" | "sm" | "lg"',
      default: '"default"',

    },

      type: "boolean",

    },
  }}

Set `aria-current` on the rendered element to mark the current item; `disabled` (buttons) or
`aria-disabled` dims it.

### ItemMedia

<TypeTable
  type={{
    variant: {

`ItemSeparator` takes the [Separator](/docs/components/separator) props. Every other part renders a
`<div>` (`ItemDescription` a `<p>`) and takes that element's props.
