## Installation

```bash
npx shadcn@latest add @hbd/spinner
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/spinner.json
```

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";
```

```tsx
<Spinner />
```

## Examples

### Size

Here Be Dragons addition — four fixed sizes: `sm` (16px), `default` (24px), `lg` (40px) and `xl` (64px).

  </Tab>
</Tabs>

### Variant

Here Be Dragons addition — `default` draws the arc in the action crimson, `muted` dims it, and
`inherit` follows the current text colour for coloured surfaces.

### Button

Inside a `Button` the spinner takes the button's icon size and text colour, so no props are needed.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Button disabled><Spinner />Saving…</Button>
      <Button variant="secondary" disabled><Spinner />Loading</Button>
      <Button variant="gold" size="sm" disabled><Spinner />Forging</Button>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Button } from "@/components/ui/button";
    import { Spinner } from "@/components/ui/spinner";

    <Button disabled>
      <Spinner />
      Saving…
    </Button>
    <Button variant="secondary" disabled>
      <Spinner />
      Loading
    </Button>
    <Button variant="gold" size="sm" disabled>
      <Spinner />
      Forging
    </Button>
    ```

  </Tab>
</Tabs>

### Accessible label

The spinner is a `role="status"` element named "Loading". Override the name with `aria-label`.

<Tabs items={["Preview", "Code"]}>

    </Preview>
  </Tab>

  </Tab>
</Tabs>
