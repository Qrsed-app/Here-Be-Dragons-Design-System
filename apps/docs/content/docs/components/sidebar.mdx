The preview above uses `collapsible="none"` so the rail stays inside the page. A real sidebar is
`fixed`, full height, and collapses — see the layout below.

## Installation

```bash
npx shadcn@latest add @hbd/sidebar
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/sidebar.json
```

It brings Button, Input, Separator, Sheet, Skeleton and Tooltip with it, plus the `use-mobile`
hook — below `768px` the rail becomes a Sheet.

## Usage

A sidebar lives in three files: the provider in your layout, the rail itself, and the page.

```tsx title="app/layout.tsx"
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar";
import { AppSidebar } from "@/components/app-sidebar";

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  );
}
```

```tsx title="components/app-sidebar.tsx"
import {
  Sidebar,
  SidebarContent,
  SidebarFooter,
  SidebarGroup,
  SidebarHeader,
} from "@/components/ui/sidebar";

export function AppSidebar() {
  return (
    <Sidebar>
      <SidebarHeader />
      <SidebarContent>
        <SidebarGroup />
        <SidebarGroup />
      </SidebarContent>
      <SidebarFooter />
    </Sidebar>
  );
}
```

```tsx title="app/page.tsx"
import { SidebarInset, SidebarTrigger } from "@/components/ui/sidebar";

export default function Page() {
  return (
    <SidebarInset>
      <SidebarTrigger />
      <h1>Atlas</h1>
    </SidebarInset>
  );
}
```

`SidebarProvider` owns the open state, remembers it in a cookie, and binds <kbd>⌘</kbd>+<kbd>B</kbd>
to toggle it.

## Examples

### Groups, badges and sub-menus

`SidebarGroupLabel` is the small-caps eyebrow over a block of rows. `SidebarMenuBadge` pins a count
to the right of a row, and `SidebarMenuSub` nests child links under it — all shown in the preview
at the top of this page.

```tsx
<SidebarGroup>
  <SidebarGroupLabel>Voyage</SidebarGroupLabel>
  <SidebarGroupContent>
    <SidebarMenu>
      <SidebarMenuItem>
        <SidebarMenuButton isActive>
          <MapIcon />
          <span>Atlas</span>
        </SidebarMenuButton>
        <SidebarMenuBadge>12</SidebarMenuBadge>
        <SidebarMenuSub>
          <SidebarMenuSubItem>
            <SidebarMenuSubButton href="/seas/north" isActive>
              Northern Seas
            </SidebarMenuSubButton>
          </SidebarMenuSubItem>
        </SidebarMenuSub>
      </SidebarMenuItem>
    </SidebarMenu>
  </SidebarGroupContent>
</SidebarGroup>
```

### Collapsing to icons

`collapsible="icon"` keeps a 3rem rail of icons when the sidebar is closed. Give each row a
`tooltip` so the label survives the collapse.

```tsx
<Sidebar collapsible="icon">
  …
  <SidebarMenuButton tooltip="Atlas">
    <MapIcon />
    <span>Atlas</span>
  </SidebarMenuButton>
</Sidebar>
```

### A link instead of a button

```tsx
<SidebarMenuButton asChild isActive>
  <Link href="/atlas">
    <MapIcon />
    <span>Atlas</span>
  </Link>
</SidebarMenuButton>
```

### Loading rows

```tsx
<SidebarMenu>
  {Array.from({ length: 5 }).map((_, i) => (
    <SidebarMenuItem key={i}>
      <SidebarMenuSkeleton showIcon />
    </SidebarMenuItem>
  ))}
</SidebarMenu>
```

`useSidebar()` returns `{ state, open, setOpen, openMobile, setOpenMobile, isMobile, toggleSidebar }`
for anything the parts don't cover. The remaining exports — `SidebarHeader`, `SidebarFooter`,
`SidebarContent`, `SidebarGroup`, `SidebarGroupAction`, `SidebarGroupContent`, `SidebarInput`,
`SidebarInset`, `SidebarMenu`, `SidebarMenuAction`, `SidebarMenuBadge`, `SidebarMenuSkeleton`,
`SidebarMenuSub`, `SidebarMenuSubButton`, `SidebarMenuSubItem`, `SidebarRail`, `SidebarSeparator`
and `SidebarTrigger` — take the props of the element they render.
