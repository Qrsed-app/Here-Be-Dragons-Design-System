## Installation

```bash
npx shadcn@latest add @hbd/scroll-area
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/scroll-area.json
```

## Usage

```tsx
import { ScrollArea } from "@/components/ui/scroll-area";
```

```tsx
<ScrollArea className="h-[200px] w-[350px] rounded-md border p-4">
  The Cartographer charted the Sea of Fallen Stars over forty winters, sounding every reef and
  naming every isle that rose above the tide.
</ScrollArea>
```

The scrollbar appears while the pointer is over the area and darkens under the pointer.
