## Installation

```bash
npx shadcn@latest add @hbd/command
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/command.json
```

This also installs [Dialog](/docs/components/dialog), which `CommandDialog` is built on.

## Usage

```tsx
import {
  Command,
  CommandDialog,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
  CommandShortcut,
} from "@/components/ui/command";
```

```tsx
<Command>
  <CommandInput placeholder="Type a command or search..." />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandGroup heading="Suggestions">
      <CommandItem>Calendar</CommandItem>
      <CommandItem>Search Emoji</CommandItem>
      <CommandItem>Calculator</CommandItem>
    </CommandGroup>
    <CommandSeparator />
    <CommandGroup heading="Settings">
      <CommandItem>Profile</CommandItem>
      <CommandItem>Billing</CommandItem>
      <CommandItem>Settings</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>
```

The list uses the Here Be Dragons select look: the row under the keyboard or pointer gets the ink
focus ring, hovered rows darken, and the list scrolls past 280px.

### Chosen Item

Here Be Dragons addition — set `data-checked` on the item that holds the current value to give it
the select's gold edge. This is how the [Combobox](/docs/components/combobox) marks its value.

<Tabs items={["Preview", "Code"]}>

      <CommandCheckedDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { CheckIcon } from "lucide-react";

    const schools = ["Abjuration", "Conjuration", "Divination", "Enchantment", "Evocation"];
    const [school, setSchool] = React.useState("Evocation");

    <Command className="w-64 rounded-md border border-border-subtle shadow-md">
      <CommandInput placeholder="Search schools…" />
      <CommandList>
        <CommandEmpty>No school found.</CommandEmpty>
        <CommandGroup>
          {schools.map((s) => (
            <CommandItem key={s} value={s} data-checked={school === s} onSelect={setSchool}>
              {s}
              <CheckIcon
                className={
                  school === s ? "ml-auto size-3.5 text-gold-deep" : "ml-auto size-3.5 opacity-0"
                }
              />
            </CommandItem>
          ))}
        </CommandGroup>
      </CommandList>
    </Command>
    ```

## API Reference

### CommandDialog

<TypeTable
  type={{
    title: {
      type: "string",
      default: '"Command Palette"',
      description: "Accessible dialog title, visually hidden.",
    },
    description: {
      type: "string",
      default: '"Search for a command to run..."',
      description: "Accessible dialog description, visually hidden.",
    },
    showCloseButton: {
      type: "boolean",
      default: "true",
      description: "Show the dialog's close button at the end of the search band.",
    },
  }}
/>

Every other `CommandDialog` prop goes to [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog)'s
`Root`.

### CommandItem

<TypeTable
  type={{
    "data-checked": {
      type: "boolean",
      default: "false",
      description:
        "Here Be Dragons addition. Marks the item holding the current value with the select's gold edge and medium weight.",
    },
  }}
/>

`Command`, `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup`, `CommandItem` and
`CommandSeparator` take the props of their [cmdk](https://github.com/pacocoursey/cmdk) parts —
`value`, `onSelect`, `disabled` and `keywords` on items, `shouldFilter` and `filter` on `Command`.
`CommandShortcut` renders a `<span>`.
