## Installation

```bash
npx shadcn@latest add @hbd/kbd
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/kbd.json
```

## Usage

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd";
```

```tsx
<Kbd>Ctrl</Kbd>
```

New in Here Be Dragons — there was no keyboard key before. It is drawn as a small raised parchment
keycap in JetBrains Mono, with an ink edge and a one-pixel offset shadow echoing the buttons.

## API Reference

`Kbd` renders a `<kbd>` and `KbdGroup` a `<kbd>` wrapper; neither adds props. Inside an element with
`data-slot="tooltip-content"` the key switches to a translucent cap that reads on the tooltip.
