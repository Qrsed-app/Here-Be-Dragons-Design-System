## Installation

```bash
npx shadcn@latest add @hbd/drawer
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/drawer.json
```

## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer";
```

```tsx
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

The drawer is a touch-first bottom sheet that can be dragged shut. For a panel that slides in from
an edge on desktop, use [Sheet](/docs/components/sheet).

## API Reference

The components add no props of their own. `Drawer` takes Vaul's root props (`direction`,
`snapPoints`, `dismissible`, `open`, `onOpenChange`…) and the other parts forward to the matching
Vaul parts — see the [Vaul documentation](https://vaul.emilkowal.ski/api). `DrawerContent` renders
the portal, overlay and, for bottom drawers, the drag handle. `DrawerHeader` and `DrawerFooter`
render a `<div>`.
