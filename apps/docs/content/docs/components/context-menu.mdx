## Installation

```bash
npx shadcn@latest add @hbd/context-menu
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/context-menu.json
```

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@/components/ui/context-menu";
```

```tsx
<ContextMenu>
  <ContextMenuTrigger>Right click</ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>Profile</ContextMenuItem>
    <ContextMenuItem>Billing</ContextMenuItem>
    <ContextMenuItem>Team</ContextMenuItem>
    <ContextMenuItem>Subscription</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

The menu opens at the pointer on right click, or after a long press on touch screens. It shares the
panel, items, labels and destructive styling of the [Dropdown Menu](/docs/components/dropdown-menu).

## API Reference

### ContextMenuItem

<TypeTable
  type={{
    variant: {
      type: '"default" | "destructive"',
      default: '"default"',
      description: "`destructive` writes the item in blood and tints its highlight.",
    },
    inset: {
      type: "boolean",
      default: "false",
      description: "Indent the item to align with items that have an icon.",
    },
  }}
/>

`ContextMenuLabel` and `ContextMenuSubTrigger` take the same `inset` prop. The panel is between 160px
and 280px wide unless you set a width. Every other prop goes to the matching part of
[Radix Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu);
`ContextMenuShortcut` renders a `<span>`.
