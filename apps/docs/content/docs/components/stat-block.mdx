Here Be Dragons component — shadcn/ui has no counterpart. It follows the shadcn conventions: one
named export per part, a `data-slot` on each, and `className` merged last.

## Installation

```bash
npx shadcn@latest add @hbd/stat-block
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/stat-block.json
```

## Usage

```tsx
import {
  StatBlock,
  StatBlockAbilities,
  StatBlockDescription,
  StatBlockHeader,
  StatBlockProperties,
  StatBlockProperty,
  StatBlockPropertyLabel,
  StatBlockPropertyValue,
  StatBlockSection,
  StatBlockSectionTitle,
  StatBlockSeparator,
  StatBlockTitle,
  StatBlockTrait,
  StatBlockTraitName,
} from "@/components/ui/stat-block";
```

```tsx
<StatBlock>
  <StatBlockHeader>
    <StatBlockTitle>Goblin</StatBlockTitle>
    <StatBlockDescription>Small humanoid (goblinoid), neutral evil</StatBlockDescription>
  </StatBlockHeader>
  <StatBlockSeparator />
  <StatBlockAbilities str={8} dex={14} con={10} int={10} wis={8} cha={8} />
</StatBlock>
```

## API Reference

### StatBlock

<TypeTable
  type={{
    size: {
      type: '"default" | "sm"',
      default: '"default"',
      description:
        "`sm` is the compact layout: tighter padding, smaller title, property, trait and section type.",
    },
  }}
/>

Renders an `<article>` (max width `24rem`); other props go to it. Give it an `aria-label` such as
`"Goblin stat block"`.

### StatBlockAbilities

<TypeTable
  type={{
    str: { type: "number | string", description: "Strength score." },
    dex: { type: "number | string", description: "Dexterity score." },
    con: { type: "number | string", description: "Constitution score." },
    int: { type: "number | string", description: "Intelligence score." },
    wis: { type: "number | string", description: "Wisdom score." },
    cha: { type: "number | string", description: "Charisma score." },
  }}
/>

Renders the six-column `<table>` with a visually hidden “Ability scores” caption and computes each
modifier (`+2`, `−1`). A missing score shows `—`. Other props go to the `<table>`. The same
calculation is exported as `getAbilityModifier(score)`.

### Other parts

Each part forwards its props to the element it renders.

| Part                                                                      | Element                                     |
| ------------------------------------------------------------------------- | ------------------------------------------- |
| `StatBlockHeader`                                                         | `<header>`                                  |
| `StatBlockDescription`                                                    | `<p>`, italic subtitle                      |
| `StatBlockSeparator`                                                      | `<hr>`, red rule                            |
| `StatBlockProperties`                                                     | `<dl>`                                      |
| `StatBlockProperty` / `StatBlockPropertyLabel` / `StatBlockPropertyValue` | `<div>` / `<dt>` / `<dd>`                   |
| `StatBlockSection`                                                        | `<section>`                                 |
| `StatBlockTrait` / `StatBlockTraitName`                                   | `<div>` / `<span>`, bold italic run-in name |
