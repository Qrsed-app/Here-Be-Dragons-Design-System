## Installation

```bash
npx shadcn@latest add @hbd/button
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/button.json
```

## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button variant="outline">Button</Button>
```

Every other prop is forwarded to the `<button>` element — or to the child when `asChild` is set.
The exported `buttonVariants` helper returns the same classes for use on non-button elements.
