## Installation

```bash
npx shadcn@latest add @hbd/hover-card
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/hover-card.json
```

## Usage

```tsx
import { HoverCard, HoverCardContent, HoverCardTrigger } from "@/components/ui/hover-card";
```

```tsx
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>The Cartographer charts the Sea of Fallen Stars.</HoverCardContent>
</HoverCard>
```

## API Reference

### HoverCardContent

<TypeTable
  type={{
    showArrow: {
      type: "boolean",
      default: "true",
      description: "Draw the arrow on the edge facing the trigger. Here Be Dragons addition.",
    },
    sideOffset: {
      type: "number",
      default: "8",
      description: "Gap in px between trigger and card; the arrow fills it.",
    },
    align: {
      type: '"start" | "center" | "end"',
      default: '"center"',
      description: "Alignment against the trigger.",
    },
  }}
/>

Every other prop goes to Radix `HoverCard.Content`. `HoverCard` and `HoverCardTrigger` take the
props of their [Radix Hover Card](https://www.radix-ui.com/primitives/docs/components/hover-card)
parts.
