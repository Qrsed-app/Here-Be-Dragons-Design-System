## Installation

```bash
npx shadcn@latest add @hbd/popover
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/popover.json
```

## Usage

```tsx
import { Popover, PopoverContent, PopoverTrigger } from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent>Place content for the popover here.</PopoverContent>
</Popover>
```

## API Reference

### PopoverContent

<TypeTable
  type={{
    showArrow: {
      type: "boolean",
      default: "true",
      description: "Draw the arrow on the edge facing the trigger. Here Be Dragons addition.",
    },
    sideOffset: {
      type: "number",
      default: "8",
      description: "Gap in px between trigger and panel; the arrow fills it.",
    },
    align: {
      type: '"start" | "center" | "end"',
      default: '"center"',
      description: "Alignment against the trigger.",
    },
  }}
/>

Every other prop goes to Radix `Popover.Content`; the panel is between 200px and 320px wide unless
you set a width. `Popover`, `PopoverTrigger`, `PopoverAnchor` and `PopoverClose` (Here Be Dragons
addition) take the props of their [Radix Popover](https://www.radix-ui.com/primitives/docs/components/popover)
parts. `PopoverHeader`, `PopoverTitle` and `PopoverFooter` (Here Be Dragons addition) render a
`<div>`, `PopoverDescription` a `<p>`.
