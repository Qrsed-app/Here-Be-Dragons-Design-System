Here Be Dragons component — shadcn/ui has no chip. It follows the shadcn conventions: `variant` and
`size` from `cva`, `asChild`, a `data-slot` on each part, and the pressable form built on the Radix
Toggle primitive.

## Installation

```bash
npx shadcn@latest add @hbd/chip
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/chip.json
```

## Usage

```tsx
import { Chip, ChipRemove, ChipToggle } from "@/components/ui/chip";
```

```tsx
<Chip variant="success">Verified</Chip>
```

### Removable

Add a `ChipRemove` after the label and drop the chip from your state in its `onClick`. Name the chip
in its `aria-label`.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <ChipRemovableDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    "use client";

    import * as React from "react";

    import { Chip, ChipRemove } from "@/components/ui/chip";

    const INITIAL_TAGS = ["Compass", "Astrolabe", "Sextant", "Cartography"];

    export function ChipRemovableDemo() {
      const [tags, setTags] = React.useState(INITIAL_TAGS);

      if (tags.length === 0) {
        return (
          <Chip asChild outline>
            <button type="button" onClick={() => setTags(INITIAL_TAGS)}>
              Reset tags
            </button>
          </Chip>
        );
      }

      return (
        <>
          {tags.map((label) => (
            <Chip key={label} variant="primary">
              {label}
              <ChipRemove
                aria-label={`Remove ${label}`}
                onClick={() => setTags((prev) => prev.filter((tag) => tag !== label))}
              />
            </Chip>
          ))}
        </>
      );
    }
    ```

  </Tab>
</Tabs>

### Toggle

`ChipToggle` is a pressable chip built on the Radix Toggle: a `<button>` with `aria-pressed` that
fills with the primary colour when on.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <ChipToggleDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    "use client";

    import * as React from "react";

    import { ChipToggle } from "@/components/ui/chip";

    const FILTERS = ["Dragons", "Maps", "Lore", "Sea Monsters"];

    export function ChipToggleDemo() {
      const [selected, setSelected] = React.useState<string[]>(["Dragons"]);

      return (
        <>
          {FILTERS.map((label) => (
            <ChipToggle
              key={label}
              pressed={selected.includes(label)}
              onPressedChange={(pressed) =>
                setSelected((prev) => (pressed ? [...prev, label] : prev.filter((l) => l !== label)))
              }
            >
              {label}
            </ChipToggle>
          ))}
        </>
      );
    }
    ```

  </Tab>
</Tabs>

Every other prop goes to the `<span>`. The exported `chipVariants` returns the same classes for use
on other elements.

### ChipToggle

Takes the same `variant`, `size` and `outline` props as `Chip`, plus the Radix Toggle props
`pressed`, `defaultPressed`, `onPressedChange` and `disabled`. See the
[Radix Toggle](https://www.radix-ui.com/primitives/docs/components/toggle) documentation.

### ChipRemove

A `<button type="button">` with a 32px hit area around a 16px ✕. It defaults to
`aria-label="Remove"` — pass one that names the chip. Children replace the icon; other props go to
the `<button>`. Put it inside a `Chip`, never inside a `ChipToggle` (a button cannot contain a
button).
