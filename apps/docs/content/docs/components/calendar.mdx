## Installation

```bash
npx shadcn@latest add @hbd/calendar
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/calendar.json
```

## Usage

```tsx
import { Calendar } from "@/components/ui/calendar";
```

```tsx
<Calendar mode="single" selected={date} onSelect={setDate} />
```

The calendar is [React DayPicker](https://daypicker.dev) with the Here Be Dragons look: a raised
parchment surface, a Cinzel month caption, round blood-red selected days, and a ring on the day the
grid's arrow keys will move from. Everything DayPicker accepts — `mode`, `numberOfMonths`,
`startMonth` / `endMonth`, `disabled`, `locale`, `formatters` — is accepted here.

run, and each edge half-fills its cell toward it.

      description:
        "Override the caption, weekday and day text. Weekdays default to the three-letter form the Here Be Dragons calendar has always used.",

Every other prop is forwarded to `DayPicker` — see the
[React DayPicker API](https://daypicker.dev/api/interfaces/DayPickerProps). The day cell size comes
from a `--cell-size` custom property on the root, so `className="[--cell-size:--spacing(10)]"`
scales the grid.

### CalendarDayButton

The single day button, exported so `components={{ DayButton: … }}` can wrap it. It takes DayPicker's
`day` and `modifiers` plus the props of [Button](/docs/components/button).
