## Installation

```bash
npx shadcn@latest add @hbd/badge
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/badge.json
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";
```

```tsx
<Badge variant="outline">Badge</Badge>
```

### Count

A number in a badge. The badge is at least as wide as it is tall, so single digits stay round.
Cap large values yourself and put the real count in the accessible name.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Badge>3</Badge>
      <Badge>42</Badge>
      <Badge variant="destructive" aria-label="128">
        99+
      </Badge>
      <Badge variant="destructive" aria-label="Notifications, 1500">
        999+
      </Badge>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    function formatCount(count: number, max = 99) {
      return count > max ? `${max}+` : String(count);
    }

    <Badge>3</Badge>
    <Badge>42</Badge>
    <Badge variant="destructive" aria-label="128">
      {formatCount(128)}
    </Badge>
    <Badge variant="destructive" aria-label="Notifications, 1500">
      {formatCount(1500, 999)}
    </Badge>
    ```

  </Tab>
</Tabs>

### Dot

`aria-label` when the colour means something.

## API Reference

<TypeTable
  type={{
    variant: {
      type: '"default" | "secondary" | "destructive" | "outline" | "ghost" | "link" | "success" | "warning"',
      default: '"default"',
      description: "Visual style. `success` and `warning` are Here Be Dragons additions.",
    },
    asChild: {
      type: "boolean",
      default: "false",
      description:
        "Render the single child element instead of a `<span>`, merging props and classes onto it (Radix Slot).",
    },
  }}
/>

Every other prop is forwarded to the `<span>` element — or to the child when `asChild` is set.
The exported `badgeVariants` helper returns the same classes for use on other elements.
