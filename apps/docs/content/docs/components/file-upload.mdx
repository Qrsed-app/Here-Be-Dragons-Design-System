A Here Be Dragons component: shadcn/ui has no file upload. The root owns the files and the
validation; the dropzone, the list and each row are composed around it.

## Installation

```bash
npx shadcn@latest add @hbd/file-upload
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/file-upload.json
```

## Usage

```tsx
import {
  FileUpload,
  FileUploadDropzone,
  FileUploadItem,
  FileUploadItemDelete,
  FileUploadItemMetadata,
  FileUploadItemPreview,
  FileUploadItemProgress,
  FileUploadItemStatus,
  FileUploadList,
} from "@/components/ui/file-upload";
```

```tsx
<FileUpload value={files} onValueChange={setFiles} accept="image/*" multiple>
  <FileUploadDropzone />
  <FileUploadList>
    {files.map((file) => (
      <FileUploadItem key={file.name} file={file}>
        <FileUploadItemPreview />
        <FileUploadItemMetadata />
        <FileUploadItemDelete />
      </FileUploadItem>
    ))}
  </FileUploadList>
</FileUpload>
```

`FileUploadDropzone` with no children draws the arrow, the "Drag files here or browse" prompt, and
a line summarising `accept`, `maxSize` and `maxFiles`. Give it children to draw something else.

`FileUploadItemProgress` inside `FileUploadItemMetadata` and the bar sits under the file name, its
fill turning green when the row completes and red when it fails.

### Rejected files

A file that fails `accept`, `maxSize` or `maxFiles` is never added; `onFileReject` reports it with a
reason so you can say why.

### FileUploadDropzone

The drop target and picker button: a `<div role="button">` taking every div prop. It carries
`data-drag-over` while a drag is over it, and `aria-invalid` paints the border red.

### FileUploadItem

<TypeTable
  type={{
    file: { type: "File", description: "The file this row describes." },
    status: {
      type: '"idle" | "uploading" | "complete" | "error"',
      default: '"idle"',
      description: "Drives the status icon and the progress fill colour.",
    },
    progress: { type: "number", default: "0", description: "Percent complete, 0 to 100." },
    error: {
      type: "string",
      description: "Message shown under the file name when status is `error`.",
    },
  }}
/>

`FileUploadItemPreview` shows an image thumbnail or a document glyph, `FileUploadItemMetadata`
the name, size and error — plus any children, which is where `FileUploadItemProgress` goes —
`FileUploadItemStatus` the tick or warning, and `FileUploadItemDelete` the remove button.
`FileUploadTrigger` opens the picker from anywhere else on the page.
