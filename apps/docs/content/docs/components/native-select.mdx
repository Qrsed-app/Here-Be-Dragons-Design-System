## Installation

```bash
npx shadcn@latest add @hbd/native-select
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/native-select.json
```

## Usage

```tsx
import {
  NativeSelect,
  NativeSelectOptGroup,
  NativeSelectOption,
} from "@/components/ui/native-select";
```

```tsx
<NativeSelect>
  <NativeSelectOption value="">Select a fruit</NativeSelectOption>
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
</NativeSelect>
```

The closed control matches the old custom select's trigger, chevron included. The open list is the
browser's own.

## API Reference

<TypeTable
  type={{
    size: {
      type: '"sm" | "default" | "lg"',
      default: '"default"',
      description: "Height, padding and type size. `lg` is a Here Be Dragons addition.",
    },
    "aria-invalid": {
      type: "boolean",
      description: "Error border and blood-red text.",
    },
    "data-valid": {
      type: "boolean",
      description: "Here Be Dragons addition. Success border and forest-green text.",
    },
  }}
/>

Every other prop goes to the `<select>`; `className` styles the select, not its wrapper. Inside a
vertical [Field](/docs/components/field) the wrapper stretches to the field's width, otherwise it
fits its longest option. `NativeSelectOption` and `NativeSelectOptGroup` forward to `<option>` and
`<optgroup>`.
