## Installation

```bash
npx shadcn@latest add @hbd/textarea
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/textarea.json
```

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";
```

```tsx
<Textarea />
```

Like upstream, the textarea grows with its content (`field-sizing: content`) from a 96px minimum
up to 400px, then scrolls. Browsers without `field-sizing` fall back to `rows`.

### Character Count

The old `maxLength` counter is a composition: a footer row with the description on the left and the
count on the right, turning gold at 80% and blood-red at the limit.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <TextareaCountDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    "use client";

    import * as React from "react";
    import { cn } from "@/lib/utils";
    import { Field, FieldDescription, FieldLabel } from "@/components/ui/field";
    import { Textarea } from "@/components/ui/textarea";

    const MAX = 120;

    export function TextareaCountDemo() {
      const [value, setValue] = React.useState("Here be dragons.");

      return (
        <Field className="max-w-md">
          <FieldLabel htmlFor="bio">Bio</FieldLabel>
          <Textarea
            id="bio"
            maxLength={MAX}
            value={value}
            onChange={(event) => setValue(event.target.value)}
          />
          <div className="flex items-start justify-between gap-2">
            <FieldDescription>Keep it brief.</FieldDescription>
            <FieldDescription
              aria-live="polite"
              className={cn(
                "ms-auto text-right",
                value.length >= MAX * 0.8 && "text-gold-deep",
                value.length >= MAX && "font-medium text-foreground-emphasis",
              )}
            >
              {value.length}/{MAX}
            </FieldDescription>
          </div>
        </Field>
      );
    }
    ```

  </Tab>
</Tabs>
