Here Be Dragons component — shadcn/ui has no counterpart. The banner fills the viewport
(`min-h-screen`); the examples on this page cap it with `min-h-[32rem]`. Wrap a full-page banner in
`<main>` and set `document.title` to match its message.

## Installation

```bash
npx shadcn@latest add @hbd/full-banner
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/full-banner.json
```

## Usage

```tsx
import {
  FullBanner,
  FullBannerActions,
  FullBannerContent,
  FullBannerDescription,
  FullBannerEyebrow,
  FullBannerMedia,
  FullBannerMeta,
  FullBannerTitle,
} from "@/components/ui/full-banner";
```

```tsx
<FullBanner>
  <FullBannerContent>
    <FullBannerMedia>{/* decorative SVG */}</FullBannerMedia>
    <FullBannerEyebrow>No Connection</FullBannerEyebrow>
    <FullBannerTitle>You’re offline</FullBannerTitle>
    <FullBannerDescription>Check your arcane connection and try again.</FullBannerDescription>
    <FullBannerActions>
      <Button>Retry</Button>
    </FullBannerActions>
    <FullBannerMeta>Last synced 3 minutes ago</FullBannerMeta>
  </FullBannerContent>
</FullBanner>
```

has one.
