A Here Be Dragons component: shadcn/ui has no stepper. It is a native `<input type="number">` with
its own − and + buttons, so `id`, `name`, `required`, `aria-invalid` and the rest go straight to
the input.

## Installation

```bash
npx shadcn@latest add @hbd/stepper
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/stepper.json
```

## Usage

```tsx
import { Stepper } from "@/components/ui/stepper";
```

```tsx
<Stepper defaultValue={1} min={0} max={10} onValueChange={(value) => console.log(value)} />
```

The input is the only tab stop: the buttons are for pointers, and the keyboard steps with the arrow
keys, `PageUp` / `PageDown` for ten steps, and `Home` / `End` for `min` / `max`. Typing is left
alone until it settles — `onValueChange` fires when a step, an arrow key or a blur commits a
number, clamped to the bounds and rounded to the step's precision.

### Thin

`variant="thin"` shrinks the control to the width of its digits so it can sit in a table cell or
beside other fields. Wrap it in an inline column rather than a `Field`, which stretches its
children to full width.

`className` styles the bordered group; reach the field itself with `[&>input]:…`. Every other prop —
`id`, `name`, `required`, `disabled`, `aria-invalid`, `onChange`, `onBlur` — is forwarded to the
`<input type="number">`.
