## Installation

```bash
npx shadcn@latest add @hbd/input-otp
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/input-otp.json
```

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp";
```

```tsx
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

Built on [input-otp](https://input-otp.rodz.dev): paste, autofill and keyboard navigation come from
a single hidden input. Slots are separate ink-bordered cells, filled cells take the subtle parchment
surface, and the active cell gets the gold focus ring.

### Pattern

The old `type="alphanumeric"`. `pattern` takes any regular expression source; `input-otp` also
exports `REGEXP_ONLY_DIGITS`, `REGEXP_ONLY_CHARS` and `REGEXP_ONLY_DIGITS_AND_CHARS`.

              <InputOTPSlot index={4} />
              <InputOTPSlot index={5} />
            </InputOTPGroup>
          </InputOTP>
          <FieldDescription>
            {value === "" ? "Enter the 6-digit code we sent by raven." : `You entered: ${value}`}
          </FieldDescription>
        </Field>
      );
    }

## API Reference

### InputOTP

<TypeTable
  type={{

  }}

Every other prop (`value`, `onChange`, `onComplete`, `pattern`, `disabled`, …) goes to
[`OTPInput`](https://github.com/guilhermerodz/input-otp#api-reference).
