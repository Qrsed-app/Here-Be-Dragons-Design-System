## Installation

```bash
npx shadcn@latest add @hbd/sonner
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/sonner.json
```

Then add the `Toaster` once, in your root layout:

```tsx title="app/layout.tsx"
import { Toaster } from "@/components/ui/sonner";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <main>{children}</main>
        <Toaster />
      </body>
    </html>
  );
}
```

## Usage

```tsx
import { toast } from "sonner";
```

### Description and action

With a `description`, the message becomes a bold title. The `action` renders as an underlined link
that dismisses the toast after running. `duration: Infinity` keeps the toast until it is closed.

## API Reference

### Toaster

`Toaster` wraps Sonner's `Toaster` and styles every toast through `toastOptions.classNames`, so
`toast()` calls from `"sonner"` get the Here Be Dragons look. It changes these defaults:

<TypeTable
  type={{
    position: {
      type: '"top-left" | "top-center" | "top-right" | "bottom-left" | "bottom-center" | "bottom-right"',
      default: '"top-right"',
      description: "Where toasts appear.",
    },
    expand: {
      type: "boolean",
      default: "true",
      description: "Show the whole stack instead of collapsing it behind the newest toast.",
    },
    closeButton: {
      type: "boolean",
      default: "true",
      description:
        "Render the close button on every toast. Pass closeButton: false to a single toast to hide it.",
    },
    duration: {
      type: "number",
      default: "5000",
      description: "Milliseconds before a toast closes. The countdown bar runs for this duration.",
    },
    gap: {
      type: "number",
      default: "8",
      description: "Space in px between stacked toasts.",
    },
    offset: {
      type: "number | string",
      default: "16",
      description: "Distance from the viewport edge.",
    },
  }}
/>

Every other prop goes to Sonner's [`Toaster`](https://sonner.emilkowal.ski/toaster). Classes you pass
in `toastOptions.classNames` are merged with the Here Be Dragons ones. The countdown bar follows the
`Toaster` duration: a toast with its own `duration` still shows the default-length bar, and it is
hidden when the reader prefers reduced motion.
