## Installation

```bash
npx shadcn@latest add @hbd/aspect-ratio
```

The `@hbd` namespace needs a one-time `registries` entry in `components.json` — see
[Installation](/docs/installation). Or add it by URL, no configuration needed:

```bash
npx shadcn@latest add http://localhost:3001/r/aspect-ratio.json
```

## Usage

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio";
```

```tsx
<AspectRatio ratio={16 / 9}>
  <img src="/coastline.jpg" alt="Aerial coastline" />
</AspectRatio>
```

The box spans the full width of its parent, so size the parent. Content is clipped to the box, and the
direct child fills it and crops with `object-fit: cover` — an `<img>`, `<video>`, `<iframe>` or
`<canvas>` needs no classes of its own.
