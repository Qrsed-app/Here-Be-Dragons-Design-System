## Welcome

**Here Be Dragons** is a D&D / fantasy design system distributed as a
[shadcn](https://ui.shadcn.com/docs/registry) custom registry. **51 components**,
React 19 + Tailwind v4, every colour / size / radius / motion backed by design
tokens — a 1:1 React port of the original framework-agnostic Web Component system.

- **Browse** components in the sidebar — grouped into Primitives, Forms,
  Feedback &amp; display, Navigation, Overlays, Pickers, and Domain (TTRPG).
- **Theme:** switch between **Light**, **Dark**, and **High contrast** with the
  switcher in the top-right.
- **Install** any component straight from this live registry:

```bash
npx shadcn@latest add http://localhost:3001/r/button.json
```

Each component page shows live previews and its own install command.
