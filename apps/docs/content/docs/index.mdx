**Here Be Dragons** is a fantasy design system distributed as a
[shadcn registry](https://ui.shadcn.com/docs/registry). You use it exactly like shadcn/ui: the CLI
copies the components into your project, with the same names, props and Radix primitives — they just
look like they were drawn in a dungeon master's notebook.

- **Drop-in.** `Button`, `Card`, `Dialog`, `DropdownMenu`, `Select`, `Sidebar`… keep their shadcn/ui
  API, so switching an existing app over is an install, not a rewrite.
- **Themed by CSS variables.** One `@hbd/theme` item merges the palette, radii and font-family
  variables into your stylesheet — light, dark and high contrast.
- **Offline-safe, and yours to change.** Fonts are a separate `@hbd/fonts` item of npm packages
  bundled with your app — take ours, or point the variables at your own.
- **Extras for tabletop apps.** Spell cards, stat blocks, a gold button, spell-school colours.

## Get started

```json title="components.json"
{
  "registries": {
    "@hbd": "http://localhost:3001/r/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @hbd/theme @hbd/fonts @hbd/button
```

Read [Installation](/docs/installation) for the details, [Theming](/docs/theming) for the
variables, then pick a component from the sidebar.
