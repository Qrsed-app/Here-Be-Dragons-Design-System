import { Divider } from "@/registry/new-york/divider/divider";

The HBD divider reproduces the legacy `.hbd-divider` look 1:1 using token-backed
component CSS. It renders an accessible `role="separator"` for structural and
labelled rules, and a decorative `aria-hidden` sigil for ornamental flourishes.

## Usage

Combine variants, colors, and style types to delineate content. The labelled and
ornamental variants are ideal for breaking up long-form parchment text.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <div
        style={{
          width: "100%",
          display: "flex",
          flexDirection: "column",
          gap: "var(--hbd-space-6, 1.5rem)",
        }}
      >
        <Divider variant="with-label" color="gold">
          Chapter II
        </Divider>
        <Divider variant="ornamental" color="gold">
          &#10071;
        </Divider>
        <Divider color="strong" styleType="double" />
      </div>
