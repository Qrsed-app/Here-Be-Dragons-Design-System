---
title: List
description: Token-backed list of static, linked, or selectable rows with leading, trailing, and action slots.
---

import { List, ListItem } from "@/registry/new-york/list/list";
import { ListSelectableDemo, ListVetoDemo } from "@/components/demos/list-demo";

The HBD list renders a semantic `<ul>` with a `<List.Item>` compound API. Items
can be static, linked (`href`), or `selectable` buttons, each with optional
`leading`, `primary`, `secondary`, `trailing`, and `action` slots. Selection
fires a cancelable `onSelect` callback that mirrors the legacy `hbd:select`
CustomEvent.

## Slots

Each item exposes `leading`, `primary`, `secondary`, `trailing`, and `action`
slots. The action region (and any trailing controls) never triggers list
selection.

## Linked items

An item with an `href` renders as an `<a>` and sets `aria-current="page"` when
`selected`. Use `flush` to strip the surrounding border for embedding in a card.

## Selectable

Mark items `selectable` to render activatable buttons. `onSelect` fires on
click, Enter, or Space with `{ index, value, item }`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <ListSelectableDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    'use client';
    import * as React from 'react';
    import { List } from '@/components/ui/list';

    const ports = [
      { value: 'tortuga', primary: 'Tortuga', secondary: 'Lawless free port' },
      { value: 'nassau', primary: 'Nassau', secondary: 'Pirate republic' },
      { value: 'port-royal', primary: 'Port Royal', secondary: 'Crown stronghold' },
    ];

    export function PortPicker() {
      const [selected, setSelected] = React.useState('nassau');
      return (
        <List bordered divided onSelect={(d) => setSelected(d.value)}>
          {ports.map((p) => (
            <List.Item
              key={p.value}
              selectable
              value={p.value}
              selected={selected === p.value}
              primary={p.primary}
              secondary={p.secondary}
            />
          ))}
        </List>
      );
    }
    ```

  </Tab>
</Tabs>

## Vetoing selection

`onSelect` is cancelable: return `false` to veto the activation, mirroring the
legacy `hbd:select` CustomEvent's `preventDefault`.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <ListVetoDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <List
      bordered
      onSelect={(detail) => {
        if (detail.value === "sealed") return false; // veto
        setSelected(detail.value);
      }}
    >
      <List.Item selectable value="chart" primary="Sea chart" />
      <List.Item selectable value="sealed" primary="Sealed scroll" />
      <List.Item selectable value="logbook" primary="Captain's logbook" />
    </List>
    ```
  </Tab>
</Tabs>
