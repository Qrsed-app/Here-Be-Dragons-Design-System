title: Toggle Group
description: A joined row of buttons for single-select (radio-like) or multi-select on/off choices.
---

import { ToggleGroup, ToggleGroupItem } from "@/registry/new-york/toggle-group/toggle-group";
import { ToggleGroupSingleDemo, ToggleGroupMultiDemo } from "@/components/demos/toggle-group-demo";

The toggle group joins a row of HBD buttons into one segmented control. It has
two modes: `single` (radio-like one-of-N, the default) and `multi` (independent
on/off per button). It mirrors the original web component's selection, keyboard,
and ARIA model — single mode is a `radiogroup` with roving tabindex and
arrow-to-select; multi mode is a `group` of toggle buttons.

## Single select

In `single` mode (the default) exactly one item is selected at a time, like a
radio group. Re-selecting the active item does not clear it.

## Multi select

Set `mode="multi"` for independent on/off buttons. Any number of items can be
active at once, and `onValueChange` reports a `{ values }` array.

## Controlled usage

Drive selection from React state with `value` + `onValueChange`. In single mode
the handler receives `{ value }`; in multi mode it receives `{ values }`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <ToggleGroupSingleDemo />
      <ToggleGroupMultiDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [value, setValue] = React.useState('grid');

    <ToggleGroup
      label="Map view"
      value={value}
      onValueChange={(detail) => setValue(detail.value)}
    >
      <ToggleGroupItem value="grid">Grid</ToggleGroupItem>
      <ToggleGroupItem value="list">List</ToggleGroupItem>
      <ToggleGroupItem value="atlas">Atlas</ToggleGroupItem>
    </ToggleGroup>

    // multi mode reports an array of values
    const [values, setValues] = React.useState(['bold']);

    <ToggleGroup
      mode="multi"
      label="Text formatting"
      value={values}
      onValueChange={(detail) => setValues(detail.values)}
    >
      <ToggleGroupItem value="bold">Bold</ToggleGroupItem>
      <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
      <ToggleGroupItem value="underline">Underline</ToggleGroupItem>
    </ToggleGroup>
    ```

  </Tab>
</Tabs>
