The HBD toast is an imperative notification system ported 1:1 from the legacy
`hbd-toast` web component. Mount a single `<ToastProvider>` (the portalled
region at the viewport edge), then fire toasts via the `useToast()` hook or the
standalone `toast()` function. Toasts auto-dismiss after 5s with a progress bar,
pause on hover/focus, cap the active stack at three, and queue any overflow.

## Variants

Four variants — `info` (default), `success`, `warning`, and `error`. Error
toasts use `role="alert"` and briefly flip the region's `aria-live` to
`assertive`; the rest use `role="status"` with `polite`.

    ```tsx
      const toast = useToast();
      return (
        <ToastProvider>
          <Button onClick={() => toast.info('Your map has been updated.')}>Info</Button>
          <Button onClick={() => toast.success('Treasure successfully buried.')}>Success</Button>

          <Button onClick={() => toast.error('The kraken breached the hull!')}>Error</Button>
        </ToastProvider>
      );
    }
    ```

## With title and action

Pass `title` for a bold heading, `action` for an inline activator, and
`duration: Infinity` to disable auto-dismiss so the toast lingers until the
reader acts on it.

    ```tsx
    toast.success('Voyage logged to the captain’s ledger.', {
      title: 'Saved',
      duration: Infinity,
      action: {
        label: 'Undo',
        onClick: () => toast.info('Reverted the last entry.'),
      },
    });
    ```

## Position

The region's placement is global and set at runtime via
`toast.setPosition(position)` — one of `top-right` (default), `top-center`,
`bottom-right`, `bottom-center`, or `bottom-left`. You can also set the initial
placement declaratively with `<ToastProvider position="bottom-left">`.
