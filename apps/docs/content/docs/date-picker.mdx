The HBD date picker is a click-triggered calendar popover built on the shared
`.hbd-field` chrome plus a portalled panel: a month header with prev/next
navigation, a weekday row, a 6×7 grid (`role="grid"` with roving tabindex and
full APG keyboard date navigation), and a Today / Clear / Cancel / Confirm
footer. It uses native `Intl.DateTimeFormat` for locale-aware text and plain
`Date` arithmetic for navigation — no external date library.

The interaction model is committed-vs-pending: opening snapshots the saved value
into a working copy, cell clicks mutate only that pending copy while the panel
stays open, **Confirm** commits and closes, and **Cancel**/**Escape** discard.
Values are ISO `YYYY-MM-DD` strings.

## Variants

Three variants are available: `date` (single, default), `date-time` (single date
plus an embedded time picker in the panel), and `date-range` (a start/end range
with hover-preview). The range variant uses `valueStart` / `valueEnd` (and their
`defaultValue*` counterparts) instead of `value`.

## States

Pass `hint` for helper text and `error` to surface a validation message. A
non-empty `error` sets `aria-invalid` and switches the field to its error state.
`disabled` locks the trigger.

    ```tsx
    />
    ```

## Bounded range

`min` and `max` (ISO `YYYY-MM-DD`) bound the selectable range. Out-of-bounds days
are disabled, and month navigation past the bounds is blocked.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>

  </Tab>
  <Tab value="Code">
    ```tsx

      placeholder="Select a date"
      min="1492-08-01"
      max="1492-08-31"
      defaultValue="1492-08-15"
    ```

## Controlled

Drive the committed value from React state with `value` and `onValueChange`. The
callback fires when the user confirms a selection.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <DatePickerControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [value, setValue] = React.useState<string | null>('1492-10-12');

    <DatePicker
      label="Landfall"
      placeholder="Select a date"
      value={value ?? undefined}
      onValueChange={setValue}
    />
    ```

  </Tab>
</Tabs>
