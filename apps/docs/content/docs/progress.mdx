---
title: Progress
description: Token-backed progress indicator with determinate, indeterminate, and segmented modes.
---

import { Progress } from "@/registry/new-york/progress/progress";

The HBD progress bar reproduces the legacy `.hbd-progress` look 1:1 using
token-backed component CSS. It supports three modes — determinate (a sized fill
bar driven by `value`), indeterminate (a shimmering bar when `value` is
omitted), and segmented (N filled cells of M via `segments`).

## Determinate

Set `value` (and optionally `max`, default `100`) to render a sized fill. Add
`label` and `showValue` to render the label row.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">

        <Progress value={3} max={5} label="Chapter 3 of 5" showValue />

    </Preview>
  </Tab>
  <Tab value="Code">

## Variants

The `variant` prop tints the fill: `default`, `success`, `warning`, and `error`.

        <Progress value={70} variant="warning" label="Warning" showValue />

## Indeterminate

Omit `value` for a shimmering bar that signals work of unknown duration.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <div style={{ width: "100%", display: "grid", gap: "var(--hbd-space-4, 1rem)" }}>
        <Progress label="Summoning…" />
        <Progress variant="warning" label="Reticulating splines…" />
      </div>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Progress label="Summoning…" />
    <Progress variant="warning" label="Reticulating splines…" />
    ```
  </Tab>
</Tabs>

## Segmented

Set `segments` to render N discrete cells; the number filled is derived from
`value` / `max`.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <div style={{ width: "100%", display: "grid", gap: "var(--hbd-space-4, 1rem)" }}>
        <Progress segments={5} value={3} max={5} label="3 of 5 quests" />
        <Progress segments={8} value={62} variant="success" label="Inventory" />
      </div>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Progress segments={5} value={3} max={5} label="3 of 5 quests" />
    <Progress segments={8} value={62} variant="success" label="Inventory" />
    ```
  </Tab>
</Tabs>
