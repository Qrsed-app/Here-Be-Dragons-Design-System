The HBD alert is the generic feedback banner — form errors, system notices, API
responses. It ports the legacy `.hbd-alert` markup 1:1 onto token-backed CSS, and
maps each `variant` to the correct ARIA role and `aria-live` politeness
(`error` → `alert`/assertive, `success` & `warning` → `status`/polite, `info` →
`note`).

## Variants

Four semantic variants, each with its own icon, colour, and accessibility wiring.

## Types

The `type` prop controls layout: `alert` (default), `banner` (full-width sticky
notice), and `inline` (compact).

## Dismissible

Set `dismissible` to render a × button. Clicking it (or calling the exposed
`dismiss()` via ref) animates the banner closed and fires `onDismiss` with the
`{ variant, type }` detail. Add `persist` to remember the dismissed state in
`localStorage`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <div style={{ width: '100%' }}>
        <AlertDismissibleDemo />
      </div>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    'use client';

    import * as React from 'react';
    import { Alert, AlertAction } from '@/components/ui/alert';

    export function AlertDismissibleDemo() {
      const [dismissed, setDismissed] = React.useState(false);

      if (dismissed) {
        return (
          <AlertAction onClick={() => setDismissed(false)}>
            Restore notice
          </AlertAction>
        );
      }

      return (
        <Alert
          variant="success"
          title="Voyage logged"
          dismissible
          onDismiss={() => setDismissed(true)}
        >
          Your chart has been saved to the ship&apos;s ledger.
        </Alert>
      );
    }
    ```

  </Tab>
</Tabs>

## With an action

Use the `AlertAction` slot for inline action buttons. It carries the
`.hbd-alert__action` styling (underline + focus ring).
