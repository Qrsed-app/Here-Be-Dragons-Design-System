---
title: Skeleton Group
description: Named layout presets that arrange skeleton shapes into recognisable loading patterns.
---

import { SkeletonGroup } from "@/registry/new-york/skeleton-group/skeleton-group";

`SkeletonGroup` composes multiple `Skeleton` shapes into ready-made loading
patterns — an avatar-and-text row, a media card, a list item, or a table row.
The group is decorative and marked `aria-hidden`, so let the containing region
own `aria-busy` while content loads.

## Card lines

The `card` preset renders a media block plus `lines` text rows (default `3`).

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>

      <SkeletonGroup preset="card" lines={5} style={{ width: "220px" }} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <SkeletonGroup preset="card" lines={2} />
    <SkeletonGroup preset="card" lines={5} />
    ```

  </Tab>
</Tabs>

## Without shimmer

Set `noShimmer` to disable the shimmer animation; it cascades to every child
skeleton. Useful for reduced-motion contexts or static placeholders.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <SkeletonGroup preset="avatar-text" noShimmer style={{ width: "320px" }} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <SkeletonGroup preset="avatar-text" noShimmer />
    ```
  </Tab>
</Tabs>
