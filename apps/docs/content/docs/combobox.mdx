The HBD combobox pairs a text input with a filterable suggestion panel following
the APG `aria-activedescendant` pattern: DOM focus stays on the input while the
active option is tracked by id. Options are authored declaratively with
`ComboboxOption` and `ComboboxGroup`.

## Modes

The `mode` prop selects the behaviour: `autocomplete` (free text, the default),
`strict` (must match a listed option), and `multi` (chips).

### Strict (with groups)

Only a listed value is valid; a non-matching entry reverts on blur and fires
`onInvalidInput`. Options can be grouped with `ComboboxGroup`, and any option
can be `disabled`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <ComboboxStrictDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Combobox, ComboboxOption, ComboboxGroup } from '@/registry/new-york/combobox/combobox';

    <Combobox
      mode="strict"
      label="Vessel class"
      placeholder="Pick a class…"
      defaultValue="caravel"
      hint="Must match a listed class."
    >
      <ComboboxGroup label="Sail">
        <ComboboxOption value="caravel">Caravel</ComboboxOption>
        <ComboboxOption value="carrack">Carrack</ComboboxOption>
        <ComboboxOption value="galleon">Galleon</ComboboxOption>
      </ComboboxGroup>
      <ComboboxGroup label="Oar">
        <ComboboxOption value="galley">Galley</ComboboxOption>
        <ComboboxOption value="longship" disabled>
          Longship (unavailable)
        </ComboboxOption>
      </ComboboxGroup>
    </Combobox>
    ```

  </Tab>
</Tabs>

### Multi

Selections render as removable chips inside the input. Backspace on an empty
input removes the last chip.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <ComboboxMultiDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Combobox, ComboboxOption } from '@/registry/new-york/combobox/combobox';

    const [values, setValues] = React.useState([{ value: 'rum', label: 'Rum' }]);

    <Combobox
      mode="multi"
      label="Provisions"
      placeholder="Add provisions…"
      values={values}
      onValuesChange={setValues}
    >
      <ComboboxOption value="hardtack">Hardtack</ComboboxOption>
      <ComboboxOption value="rum">Rum</ComboboxOption>
      <ComboboxOption value="limes">Limes</ComboboxOption>
      <ComboboxOption value="salt-pork">Salt pork</ComboboxOption>
      <ComboboxOption value="gunpowder">Gunpowder</ComboboxOption>
    </Combobox>
    ```

  </Tab>
</Tabs>

## States

Pass `error` for an invalid field (sets `aria-invalid` and renders an alert) or
`disabled` to lock the control.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <ComboboxStatesDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Combobox, ComboboxOption } from '@/registry/new-york/combobox/combobox';

    <Combobox
      label="Destination"
      placeholder="Search…"
      required
      error="Choose a destination before setting sail."
    >
      <ComboboxOption value="indies">The Indies</ComboboxOption>
      <ComboboxOption value="cathay">Cathay</ComboboxOption>
    </Combobox>

    <Combobox label="Locked route" placeholder="Search…" disabled defaultValue="indies">
      <ComboboxOption value="indies">The Indies</ComboboxOption>
      <ComboboxOption value="cathay">Cathay</ComboboxOption>
    </Combobox>
    ```

  </Tab>
</Tabs>
