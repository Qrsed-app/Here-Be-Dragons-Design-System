The HBD time picker is a token-backed port of the legacy `hbd-time-picker` web
component. The trigger opens an inline panel with roving-tabindex hour/minute
columns, an optional AM·PM column, and a click-to-type header. Arrow keys move
focus, Enter/Space select, Left/Right move between columns, and Escape closes
and discards. The committed value is an `HH:MM` (24h) string exposed through
`value` / `defaultValue` / `onValueChange`.

## Formats

Use `format="12"` for an AM·PM column; the default `format="24"` shows a 0–23
hour column. The committed value stays an `HH:MM` 24-hour string regardless of
the display format.

<Tabs items={["Preview", "Code"]}>

## States

`error` renders an alert below the field and sets the error styling; `disabled`
prevents the panel from opening.

## Controlled

Drive the committed value from React with `value` and `onValueChange`. The
callback fires on Confirm; Cancel, Escape, and outside-click discard the working
selection.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <TimePickerControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [value, setValue] = React.useState<string | null>('11:45');

    <TimePicker aria-label="Eight bells" value={value} onValueChange={setValue} />
    ```

  </Tab>
</Tabs>
