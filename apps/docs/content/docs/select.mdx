The HBD select is a fully-accessible custom select built as a combobox +
listbox pattern (a native `<select>` can't be styled to the HBD spec). It reuses
the shared `.hbd-field` chrome from the input and authors its option model
declaratively through the `SelectOption` and `SelectGroup` members. A
hidden native `<select>` mirrors the value for form submission.

It works uncontrolled (`defaultValue`) or controlled (`value` +
`onValueChange`), and supports placeholders, grouped options, disabled options,
hint text, error messages, and three sizes. Re-selecting the current value
clears it.

## Grouped options

Wrap options in `SelectGroup` to render non-selectable headings. Disabled
options are skipped by keyboard navigation and type-to-search.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <SelectGroupedDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Select, SelectOption, SelectGroup } from '@/components/ui/select';

    <Select label="Vessel class" placeholder="Pick a class…" defaultValue="caravel">
      <SelectGroup label="Sail">
        <SelectOption value="caravel">Caravel</SelectOption>
        <SelectOption value="carrack">Carrack</SelectOption>
        <SelectOption value="galleon">Galleon</SelectOption>
      </SelectGroup>
      <SelectGroup label="Oar">
        <SelectOption value="galley">Galley</SelectOption>
        <SelectOption value="longship" disabled>
          Longship (unavailable)
        </SelectOption>
      </SelectGroup>
    </Select>
    ```

  </Tab>
</Tabs>

## States

Pass `hint` for helper text and `error` to surface a validation message. A
non-empty `error` sets `aria-invalid` and switches the field to its error state.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <SelectStatesDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Select label="Cargo hold" placeholder="Select cargo…" hint="Heavier cargo slows the ship.">
      <SelectOption value="spices">Spices</SelectOption>
      <SelectOption value="silk">Silk</SelectOption>
      <SelectOption value="gold">Gold</SelectOption>
    </Select>

    <Select
      label="Destination"
      placeholder="Select…"
      required
      error="Choose a destination before setting sail."
    >
      <SelectOption value="indies">The Indies</SelectOption>
      <SelectOption value="cathay">Cathay</SelectOption>
    </Select>

    <Select label="Locked route" placeholder="Select…" disabled defaultValue="indies">
      <SelectOption value="indies">The Indies</SelectOption>
      <SelectOption value="cathay">Cathay</SelectOption>
    </Select>
    ```

  </Tab>
</Tabs>

## Controlled

Drive the value from React state with `value` and `onValueChange`.

    const [value, setValue] = React.useState('lisbon');

      <SelectOption value="cadiz">Cádiz</SelectOption>
