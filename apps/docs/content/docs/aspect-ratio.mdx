---
title: Aspect Ratio
description: Layout wrapper that constrains its first child to a fixed aspect ratio.
---

import { AspectRatio } from "@/registry/new-york/aspect-ratio/aspect-ratio";

`AspectRatio` is a light-DOM layout primitive. It locks its child to a chosen
ratio using the native CSS `aspect-ratio` property, and any direct child fills
the box and crops with `object-fit: cover` — so `<img>`, `<video>`, `<iframe>`
and `<canvas>` all behave sensibly. The only prop is `ratio`.

## Ratios

The `ratio` prop accepts colon notation (`"16:9"`), slash notation (`"16/9"`),
or a raw decimal (`"1.777"`). It defaults to `16:9`.

## Portrait and ultrawide

Ratios are not limited to landscape — pass `9:16` for portrait or `21:9` for an
ultrawide cinematic crop.

## Decimal notation

A bare decimal is passed straight through to CSS, useful when the ratio comes
from a computed value.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <div style={{ width: "240px" }}>
        <AspectRatio ratio="1.85">
          <div
            role="img"
            aria-label="Cinematic placeholder"
            style={{
              display: "flex",
              alignItems: "center",
              justifyContent: "center",
              background: "var(--hbd-color-surface-raised, #e8dcc8)",
              color: "var(--hbd-color-text-primary, #1a1410)",
              fontFamily: "var(--hbd-font-ui, sans-serif)",
            }}
          >
            1.85 : 1
          </div>
        </AspectRatio>
      </div>
    </Preview>
  </Tab>

    ```tsx
        1.85 : 1
      </div>
    </AspectRatio>
    ```
  </Tab>
</Tabs>

## Usage notes

- The wrapper carries no ARIA of its own. Give the slotted child its own
  accessible name (`alt` on `<img>`, `aria-label` on `<iframe>`/`<canvas>`, or
  `role="img"` + `aria-label` on a styled `<div>`).
- It always spans `width: 100%`, so constrain it by sizing a parent element.
- Only the first child is laid out by the wrapper's `object-fit: cover` rule.
