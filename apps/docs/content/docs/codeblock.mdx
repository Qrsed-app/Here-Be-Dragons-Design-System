---
title: Code Block
description: Display-only dark code surface with an optional filename/language header, line-number gutter, and copy-to-clipboard button.
---

import { Codeblock } from "@/registry/new-york/codeblock/codeblock";

The HBD code block renders a read-only, dark code surface ported 1:1 from the
legacy `.hbd-codeblock` styles. Pass the code as the `code` prop or as string
`children`; both feed the line-count gutter and the clipboard copy. An optional
header appears when a `filename` and/or `language` is supplied.

## Basic

The simplest usage: a copyable code surface with no header.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <Codeblock code={`const dragon = { name: "Smaug", hoard: 12000 };\nconsole.log(dragon.name);`} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Codeblock } from '@/components/ui/codeblock';

    <Codeblock code={`const dragon = { name: "Smaug", hoard: 12000 };\nconsole.log(dragon.name);`} />
    ```

  </Tab>
</Tabs>

## With header

Providing `filename` and/or `language` enables the header bar. The presence of a
header also turns the block into a labelled `region` landmark for assistive tech.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Codeblock
        filename="dragon.ts"
        language="TypeScript"
        code={`export interface Dragon {\n  name: string;\n  hoard: number;\n}`}
      />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Codeblock
      filename="dragon.ts"
      language="TypeScript"
      code={`export interface Dragon {\n  name: string;\n  hoard: number;\n}`}
    />
    ```
  </Tab>
</Tabs>

## Line numbers

Set `showLines` to render a line-number gutter. The count is derived from the
code text (a single trailing newline is ignored).

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Codeblock
        filename="quest.md"
        language="Markdown"
        showLines
        code={`# The Quest\n\n1. Find the map\n2. Cross the mountains\n3. Wake the dragon`}
      />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Codeblock
      filename="quest.md"
      language="Markdown"
      showLines
      code={`# The Quest\n\n1. Find the map\n2. Cross the mountains\n3. Wake the dragon`}
    />
    ```
  </Tab>
</Tabs>

## Without copy

Set `noCopy` to hide the copy-to-clipboard button, for example when the snippet
is illustrative rather than something to lift verbatim.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <Codeblock noCopy language="Shell" code={`$ here-be-dragons summon --name Smaug`} />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Codeblock noCopy language="Shell" code={`$ here-be-dragons summon --name Smaug`} />
    ```
  </Tab>
</Tabs>

## Install

```bash
npx shadcn@latest add http://localhost:3001/r/codeblock.json
```
