The HBD card is a compound component (`Card`, `Card.Header`, `Card.Title`,
`Card.Body`, `Card.Footer`, `Card.Media`, `Card.Badge`). It reproduces the
legacy `.hbd-card` look 1:1 using token-backed component CSS, not Tailwind
utilities. You can compose the parts directly or use the convenience props
(`title`, `subtitle`, `imgSrc`/`imgAlt`, `footer`, `badge`).

## Interactive

An `interactive` card (or any card with an `href`) is keyboard-focusable and
fires `onCardClick` on click or Enter / Space. Clicks inside footer actions are
ignored so buttons keep their own behaviour.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <CardInteractiveDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    'use client';
    import * as React from 'react';
    import { Card } from '@/components/ui/card';

    function Example() {
      const [count, setCount] = React.useState(0);
      return (
        <Card
          variant="interactive"
          title="Eastern Sea Route"
          subtitle="Tap or press Enter / Space"
          onCardClick={() => setCount((c) => c + 1)}
        >
          <Card.Body>Activated {count} times.</Card.Body>
        </Card>
      );
    }
    ```

  </Tab>
</Tabs>

## Composition

Compose the sub-components directly for full control, including a footer action
row and a badge overlay.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <Card style={{ maxWidth: '20rem' }}>
        <CardBadge>New</CardBadge>
        <CardHeader>
          <CardTitle headingLevel={2}>Voyage Log</CardTitle>
          <p className="hbd-card__subtitle">Day 14 — open water</p>
        </CardHeader>
        <CardBody>Calm seas and a steady wind from the south-east.</CardBody>
        <CardFooter>
          <Button variant="primary">Read</Button>
          <Button variant="default">Archive</Button>
        </CardFooter>
      </Card>
    </Preview>
  </Tab>

        <Card.Title headingLevel={2}>Voyage Log</Card.Title>

      </Card.Header>
      <Card.Body>Calm seas and a steady wind from the south-east.</Card.Body>
      <Card.Footer>
        <Button variant="primary">Read</Button>
