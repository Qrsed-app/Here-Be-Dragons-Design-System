import { Slider } from "@/registry/new-york/slider/slider";
import { SliderControlledDemo, SliderRangeDemo } from "@/components/demos/slider-demo";

The HBD slider re-bases the legacy `hbd-slider` web component on
`@radix-ui/react-slider`, giving full keyboard support (Arrow / Home / End /
Page) for free while re-applying the exact `.hbd-slider*` classes. It supports a
single value or a two-handle range, plus optional label, value readout, ticks,
hint, and error chrome.

## Ticks

Render evenly-spaced tick marks and labels below the track with `showTicks`.
Use `tickCount` (min 2, default 5) to control how many appear.

## States

look with `role="alert"`. `disabled` greys the whole field out.

## Controlled

Pass `value` and `onValueChange` to control the slider from React state. The
callback receives a `number` for a single slider.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <SliderControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [volume, setVolume] = React.useState(40);

    <Slider
      label="Volume"
      value={volume}
      onValueChange={(v) => setVolume(v as number)}
      showValue
    />
    ```

  </Tab>
</Tabs>

## Range

Set `range` to get a two-handle slider. The value becomes a `[low, high]` tuple,
and `onValueChange` receives the tuple.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <SliderRangeDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [price, setPrice] = React.useState<[number, number]>([200, 750]);

    <Slider
      label="Price range"
      range
      min={0}
      max={1000}
      step={50}
      value={price}
      onValueChange={(v) => setPrice(v as [number, number])}
      showValue
      showTicks
    />
    ```

  </Tab>
</Tabs>
