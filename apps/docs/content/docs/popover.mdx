The HBD popover ports the legacy `hbd-popover` web component onto Radix's
non-modal popover primitive. It opens on click, portals its panel, traps focus
while open, returns focus to the trigger on close, and dismisses on Escape or an
outside click — all with the token-backed `.hbd-popover*` look applied 1:1.

Because the panel is stateful (open/close, focus trap), every example below is
rendered from a client component.

## Usage

A trigger plus a titled `PopoverContent`. The header renders automatically when
you pass a `title`, complete with the built-in ✕ close button.

  <Tab value="Code">

    import { Button } from '@/components/ui/button';

    <Popover>
      <PopoverTrigger>
        <Button variant="primary">Open popover</Button>
      </PopoverTrigger>

        Here be dragons. The waters past this marker remain uncharted.

## Placement

Set `placement` to `top`, `bottom` (default), `left`, or `right`. The panel
flips to the opposite side automatically when it would collide with the viewport.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <PopoverPlacementDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Popover, PopoverTrigger, PopoverContent } from '@/components/ui/popover';
    import { Button } from '@/components/ui/button';

    <Popover placement="top">
      <PopoverTrigger>
        <Button variant="default">top</Button>
      </PopoverTrigger>
      <PopoverContent title="Placed top">
        This panel anchors to the top of its trigger.
      </PopoverContent>
    </Popover>
    ```

## Footer actions

Pass a `footer` node to render an action row. Wrap action buttons in
`PopoverClose` (with `asChild`) so they dismiss the panel without re-deriving
the close logic.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <PopoverFooterDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    import { Popover, PopoverTrigger, PopoverContent, PopoverClose } from '@/components/ui/popover';
    import { Button } from '@/components/ui/button';

    <Popover>
      <PopoverTrigger>
        <Button variant="gold">Scuttle the ship?</Button>
      </PopoverTrigger>
      <PopoverContent
        title="Confirm"
        footer={
          <>
            <PopoverClose asChild>
              <Button variant="default" size="sm">Cancel</Button>
            </PopoverClose>
            <PopoverClose asChild>
              <Button variant="primary" size="sm">Scuttle</Button>
            </PopoverClose>
          </>
        }
      >
        This cannot be undone. The ship will be lost to the depths.
      </PopoverContent>
    </Popover>
    ```

  </Tab>
</Tabs>

Escape and outside-click dismissal still apply.
