title: Stat Block

import { StatBlock } from "@/registry/new-york/stat-block/stat-block";

The HBD stat block renders a tabletop-RPG creature sheet — name and subtitle,
basic stats (AC/HP/Speed), a six-ability score table, property rows
(saving throws, senses, languages, challenge rating) and trait/action sections.
It is purely presentational and reproduces the legacy `.hbd-stat-block__*` look 1:1.

## Basic

Supply identity props plus the basic stats and ability scores. Each present
ability score renders its computed modifier automatically.

## Traits and Actions

The `traits`, `actions`, `reactions` and `legendaryActions` props accept author
markup. Each entry is a `.hbd-stat-block__trait` with a bold `__trait-name` and an
inline `__trait-body`.

## Legendary

Set `legendary` to render the Legendary Actions section (with its accent styling).
This example also shows `savingThrows` and `immunities` property rows.

## Compact

The `compact` prop reduces padding and type scale for dense layouts such as
sidebars or encounter trackers.
