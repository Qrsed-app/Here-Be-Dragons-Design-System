---
title: Switch
description: Token-backed on/off toggle built on a native checkbox with role="switch".
---

import { Switch } from "@/registry/new-york/switch/switch";
import { SwitchControlledDemo } from "@/components/demos/switch-demo";

The HBD switch is a native `<input role="switch">` wrapped in token-backed
presentational track/thumb markup. It keeps full keyboard support (Space
toggles, the input carries the form value) and works controlled
(`checked` + `onCheckedChange`) or uncontrolled (`defaultChecked`).

## Controlled

Drive the state from React with `checked` and `onCheckedChange`.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <SwitchControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [enabled, setEnabled] = React.useState(true);

    <Switch
      checked={enabled}
      onCheckedChange={(checked) => setEnabled(checked)}
      label="Night charts"
      hint="Toggle me — the status below stays in sync."
    />
    ```

  </Tab>
</Tabs>
