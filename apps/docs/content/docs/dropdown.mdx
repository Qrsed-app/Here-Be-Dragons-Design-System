The HBD dropdown is a hand-ported menu overlay (no Radix) that reproduces the
legacy `hbd-dropdown` / `hbd-menu` behaviour 1:1 — roving tabindex, Arrow/Home/End
navigation, first-character typeahead, Enter/Space activation, Escape and
outside-click dismissal, and viewport-flipping placement. It uses ARIA
`menu` / `menuitem` semantics: items execute actions, they do not represent a value.

The `trigger` prop accepts any element (typically a `Button`); it is cloned to
receive the `aria-haspopup` / `aria-expanded` / `aria-controls` wiring. Menu
contents are declared with the compound `Dropdown.Item`, `Dropdown.Separator`,
and `Dropdown.Group` members.

## Icons & shortcuts

Items accept a leading `icon` and a trailing `shortcut` hint, both rendered
`aria-hidden` (the visible label carries the accessible name).

  <Tab value="Code">

      <Dropdown.Item value="new" icon={<span aria-hidden>＋</span>} shortcut="⌘N">
        New
      </Dropdown.Item>
      <Dropdown.Item value="open" icon={<span aria-hidden>📂</span>} shortcut="⌘O">
        Open
      </Dropdown.Item>
      <Dropdown.Item value="save" icon={<span aria-hidden>💾</span>} shortcut="⌘S">
        Save
      </Dropdown.Item>
    </Dropdown>

## Groups, separators & states

Wrap items in `Dropdown.Group` to add an uppercased heading, insert a
`Dropdown.Separator` between sections, and mark items `disabled` (skipped by
keyboard nav) or `destructive` (rendered in the blood colour).

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <DropdownGroupedDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <Dropdown trigger={<Button variant="gold">Manage map</Button>} placement="bottom-start">
      <Dropdown.Group label="Edit">
        <Dropdown.Item value="rename">Rename</Dropdown.Item>
        <Dropdown.Item value="move">Move to folder</Dropdown.Item>
        <Dropdown.Item value="lock" disabled>
          Lock (coming soon)
        </Dropdown.Item>
      </Dropdown.Group>
      <Dropdown.Separator />
      <Dropdown.Group label="Danger">
        <Dropdown.Item value="delete" destructive>
          Delete map
        </Dropdown.Item>
      </Dropdown.Group>
    </Dropdown>
    ```
  </Tab>
</Tabs>

## Controlled

Drive the open state yourself with `open` + `onOpenChange` for cases like
opening the menu from another control.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <DropdownControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [open, setOpen] = React.useState(false);

    <Dropdown
      open={open}
      onOpenChange={setOpen}
      trigger={<Button variant="primary">Menu</Button>}
    >
      <Dropdown.Item value="profile">Profile</Dropdown.Item>
      <Dropdown.Item value="settings">Settings</Dropdown.Item>
      <Dropdown.Separator />
      <Dropdown.Item value="logout" destructive>
        Log out
      </Dropdown.Item>
    </Dropdown>
    ```

  </Tab>
</Tabs>
