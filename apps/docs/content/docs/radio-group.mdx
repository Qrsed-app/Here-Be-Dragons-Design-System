title: Radio Group
description: Accessible single-select radio group with a real fieldset/legend, per-option hints, and error state.

import { RadioGroup, RadioGroupItem } from "@/registry/new-york/radio-group/radio-group";
import { RadioGroupControlledDemo } from "@/components/demos/radio-group-demo";

The HBD radio group wraps Radix `RadioGroup` in a native `<fieldset>`/`<legend>`
and re-applies the legacy `.hbd-radio` BEM classes for a 1:1 render. It supports
a declarative `items` array or `<RadioGroup.Item>` children, per-option hints, a
group-level hint and error state, and the full roving-tabindex keyboard model.

## Usage

Pass an `items` array for the common case. Use `defaultValue` for an
uncontrolled group.

  <Tab value="Preview">
    <Preview>
      <RadioGroup
        name="ship"
        label="Pick a vessel"
        defaultValue="galleon"
        items={[
          { value: 'sloop', label: 'Sloop' },

          { value: 'frigate', label: 'Frigate' },

## Compound items with hints

Use `<RadioGroup.Item>` children when you want richer option content. Each item
takes an optional `hint` rendered below its label.

<Tabs items={["Preview", "Code"]}>
  <Tab value="Preview">
    <Preview>
      <RadioGroup name="plan" label="Provisioning plan" defaultValue="standard" required>
        <RadioGroupItem value="lean" label="Lean" hint="Rations for a short crossing." />
        <RadioGroupItem value="standard" label="Standard" hint="A full hold for most voyages." />
        <RadioGroupItem value="grand" label="Grand" hint="Stocked for an ocean of months." />
      </RadioGroup>
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    <RadioGroup name="plan" label="Provisioning plan" defaultValue="standard" required>
      <RadioGroup.Item value="lean" label="Lean" hint="Rations for a short crossing." />
      <RadioGroup.Item value="standard" label="Standard" hint="A full hold for most voyages." />
      <RadioGroup.Item value="grand" label="Grand" hint="Stocked for an ocean of months." />
    </RadioGroup>
    ```
  </Tab>
</Tabs>

## States

A group-level `hint` adds helper text; `error` switches the group into the
error state and announces the message via `role="alert"`. Disabled options are
skipped by keyboard navigation.

## Controlled

Drive the selection from React with `value` + `onValueChange`. The handler
receives the legacy `{ value, name }` detail shape.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <RadioGroupControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    'use client';

    import * as React from 'react';
    import { RadioGroup } from '@/components/ui/radio-group';

    export function RoutePicker() {
      const [value, setValue] = React.useState('sea');

      return (
        <RadioGroup
          name="route"
          label="Choose your route"
          value={value}
          onValueChange={(detail) => setValue(detail.value)}
          items={[
            { value: 'sea', label: 'By sea', hint: 'Fastest, but storms lie ahead.' },
            { value: 'land', label: 'Overland', hint: 'Slower, with safer harbours.' },
            { value: 'air', label: 'By airship', hint: 'Costly, yet beyond the dragons.' },
          ]}
        />
      );
    }
    ```

  </Tab>
</Tabs>
