The HBD `Textarea` wraps a native `<textarea>` in the shared `.hbd-field` chrome —
label, hint, error/success messages, and a live character counter — using
token-backed component CSS, not Tailwind utilities. It is controlled-first: pass
`value` + `onValueChange`, or omit them and rely on `defaultValue` for an
uncontrolled field.

## States

The `error` and `success` props drive the validation chrome. A non-empty `error`
sets `aria-invalid` and shows the error message with `role="alert"`; `success`
shows only when there is no error. The `hint` is hidden while an error or success
message is visible.

## Character count

Setting `maxLength` enables the live character counter, which announces politely
as you type and warns as you approach (and exceed) the limit.

## Auto-resize

With `autoresize`, the field measures its content and grows to fit — no scrollbar,
no fixed height. Combine it with a controlled `value` to keep React in sync.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <TextareaAutoresizeDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [value, setValue] = React.useState('This field grows as you type.');

    <Textarea label="Auto-resize" autoresize value={value} onValueChange={setValue} rows={2} />
    ```

  </Tab>
</Tabs>

## Controlled

Pass `value` and `onValueChange` to own the field's state in React. `onValueChange`
fires on every keystroke with the new string.

<Tabs items={['Preview', 'Code']}>
  <Tab value="Preview">
    <Preview>
      <TextareaControlledDemo />
    </Preview>
  </Tab>
  <Tab value="Code">
    ```tsx
    const [value, setValue] = React.useState('');

    <Textarea
      label="Message"
      placeholder="Write your dispatch…"
      value={value}
      onValueChange={setValue}
    />
    ```
